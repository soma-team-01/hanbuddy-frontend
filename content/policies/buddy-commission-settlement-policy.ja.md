# HanBuddy バディ手数料・精算ポリシー

Version: 2026-10-06

本ポリシーは、バディによる活動の売上、プラットフォーム手数料、キャンセル、返金、精算に適用します。

文書のバージョンは改訂文面の識別用であり、法的な施行日を意味しません。手数料変更の事前通知、確定済み予約の保護および利用規約の改訂手続きは引き続き適用されます。

## 1. 手数料率

1. 通常のプラットフォーム手数料は実売上の合計20%で、付加価値税（VAT）と決済代行手数料を含みます。
2. 承認済みアーリーバディには、VATと決済代行手数料を含む合計15%を恒久的に適用します。
3. 合計手数料に含まれるVATと決済代行手数料は別途追加控除しません。源泉徴収、返金および支払済み精算額の調整はプラットフォーム手数料と区分します。
4. 掲載・予約受諾前に、適用される合計手数料率とそこに含まれるVATを精算画面または案内で区分して確認できるようにします。
5. 手数料率変更は30日前に通知し、変更前に確定した予約には決済時点の率を適用します。VAT法改正時には変更後の法定税率を適用します。

2026-11-30韓国標準時（KST）までにバディのオンボーディングと申請を完了した新規申請者には、審査・承認後、アーリーバディ料率を恒久的に適用します。承認が12月以降になっても、期限内に申請を完了した方は対象から除外されません。この期限は新規申請の締切であり、割引の終了日ではありません。申請完了のみで活動が自動承認されるわけではありません。

## 2. 計算基準

1. 実売上とは、クーポン等の割引後に実際に支払われた金額のうち当該活動に配分された額です。
2. 当社負担の割引は別途プロモーション条件により手数料計算前に補填できます。バディ負担の割引は割引後の額を基準にします。
3. 正常完了予約の合計手数料と精算予定額は以下で計算します。

   `合計プラットフォーム手数料 = 実売上 × 適用合計手数料率`

   `精算予定額 = 実売上 − 合計プラットフォーム手数料 − 別途精算控除・調整額`

   合計手数料に含まれるVATは追加控除項目ではありません。法定VAT率が10%の場合、税抜手数料は合計手数料 ÷ 1.1、内包VATは合計手数料から税抜額を引いた金額です。別途控除・調整は法定源泉徴収、本ポリシーに基づく返金・取消料、支払済み額の調整など根拠のある項目に限り、計算根拠を案内します。事前告知を理由にVATや決済代行手数料を重複控除することはできません。

4. 明細では予約別の実売上、割引、率、税抜手数料、VAT、合計控除額、返金、調整、最終支払額を区分します。

## 3. キャンセル・返金の反映

1. 法定撤回、当社・バディの責任、一般取消等で全額返金した金額には、手数料、VAT、バディ報酬は発生しません。
2. ツーリストの一般取消で50%返金した場合、当社が保持する残り50%を基準に手数料・VAT・精算額を計算します。
3. 返金のない一般取消・無断欠席は実売上全額を基準にします。
4. バディの責任による部分返金は残額を基準にし、全額返金時は報酬を支払いません。
5. 開始7日未満前のバディ取消には実決済額の20%を取消料として課せます。バディ無断欠席には全額返金とは別に20%を課せます。
6. 当社が先に返金した額や取消料は予定精算額と相殺できます。不足時は根拠と納付方法を文書で案内します。

## 4. 精算周期・支払

1. 完了月の末日で締め、原則として翌月最終営業日までにバディ本人名義の登録口座へ支払います。
2. 金融機関休業日の場合、翌営業日に支払うことがあります。
3. 口座誤り、本人確認未完了、税務情報不足、銀行障害による遅延は、理由と必要な措置を通知します。
4. 明細受領から14日以内に異議申立てができます。経過後も明確な計算誤りや法定権利がある場合は再検討します。

## 5. 保留・調整

次に関係する金額だけを必要な期間保留できます。

- 取消、返金、チャージバック、決済紛争の処理中
- 詐欺、架空予約、なりすまし、規約違反の合理的疑い
- 提供の有無、口座名義の確認が必要
- 法令または関係機関の適法な要請

理由、金額、解除要件を通知し、調査と無関係な確定額まで一律保留しません。

## 6. 税金・証憑

1. バディは法令に従い所得申告・納税を行います。
2. 手数料VATは当社がバディに提供するサービスへの税であり、バディ自身の売上に対する所得税・VAT等とは別です。
3. 事業者登録の有無、課税区分、所得区分および実際の供給・契約・代金受領関係により、税務請求書、請求書、領収書等の必要な証憑と発行・受領主体を確認します。当社とバディは各自の法定発行・受領義務を履行します。すべての取引で一律の方向に税務請求書を発行するものではありません。 源泉徴収の要否と税率は所得区分、実際の取引関係等の法定要件により判断し、事業者未登録者全員に一律の税率を適用しません。当社は法定の源泉徴収、徴収税額の納付および支払明細の提出義務を履行し、必要な税務情報を求めることができます。バディの申告・納税責任は当社の法定義務を免除しません。
4. 口座・税務情報を正確に保ってください。

## 7. 終了後の精算

退会や資格終了後も完了活動の確定精算額を支払います。ただし、未解決の返金、チャージバック、損害賠償、法定保存義務に関係する額は確定まで保留できます。
