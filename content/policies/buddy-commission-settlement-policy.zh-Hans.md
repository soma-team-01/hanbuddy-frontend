# HanBuddy 伙伴佣金与结算政策

Version: 2026-10-06

适用于伙伴提供活动产生的销售款、平台服务费、取消退款和结算。

本次服务条款、伙伴运营条款及伙伴佣金与结算政策修订的生效日期为2026-10-06韩国标准时间（KST）。文档版本用于标识修订文本，与生效日期分别列明。费率变更的提前通知、已确认预订的保护及服务条款的修订程序仍然适用。

## 1. 费率

1. 标准平台费合计为实际销售额的20%，包含增值税（VAT）及支付处理费。
2. 获批早期伙伴永久适用包含VAT及支付处理费的合计15%费率。
3. 合计平台费已包含的VAT及支付处理费不再另行扣除。代扣税款、退款及已支付结算款的调整与平台费分别处理。
4. 发布活动或接受预订前，应可在结算页或通知中分别确认适用的合计费率及其中包含的VAT。
5. 费率改变提前30天通知；变更前已确认预订采用付款时费率。税法变更则采用变更后的法定VAT税率。

在2026-11-30韩国标准时间（KST）前（含当日）完成伙伴入驻及申请的新申请者，经审核批准后永久适用早期伙伴费率。即使在12月或以后获批，按期完成申请者也不会因此失去资格。该日期是新申请的截止日期，不是优惠到期日。完成申请并不意味着活动自动批准。

## 2. 计算依据

1. 实际销售额指游客折扣后实付金额中分配给该活动的金额。
2. 公司承担的优惠可按另行促销条件在计费前补足；伙伴承担的优惠按折后金额计算。
3. 正常完成预订的合计平台费及预计结算金额计算如下：

   `合计平台费 = 实际销售额 × 适用合计费率`

   `预计结算 = 实际销售额 − 合计平台费 − 单独结算扣款及调整额`

   合计平台费内含的VAT不是额外扣款。法定VAT税率为10%时，不含税平台费为合计平台费 ÷ 1.1，内含VAT为合计平台费减去不含税金额。单独扣款及调整仅限有依据的项目，如法定代扣税款、本政策规定的退款与取消费及已付款项调整，并告知计算依据。提前通知不能成为重复扣除VAT或支付处理费的依据。

4. 明细分别显示每笔销售额、折扣、费率、不含税费用、VAT、总扣款、退款、调整及最终支付额。

## 3. 取消退款的反映

1. 法定撤回、公司或伙伴责任、一般取消等全额退款部分不产生平台费、其VAT或伙伴报酬。
2. 游客一般取消退50%时，以公司保留的销售额50%计算费用、VAT及结算。
3. 不退款的一般取消或未到场按全额销售计算。
4. 伙伴责任导致部分退款按余额计算；全额退款不支付报酬。
5. 伙伴在开始前不足7天取消，可收实付额20%取消费；未到场除全额退款外另可收20%取消费。
6. 公司垫付退款及伙伴取消费可抵扣待结算款；不足时书面说明依据与付款方式。

## 4. 周期与支付

1. 活动完成月份的最后一个日历日截止结算，并于次月第5个工作日之前（含当日）汇款至伙伴本人名下登记的结算账户。
2. 计算工作日时不计银行休息日。上述期限为汇款期限，实际到账时间可能因银行处理而有所不同。
3. 账户错误、未完成身份验证、税务信息缺失或银行故障可导致延迟；说明原因与必要措施。
4. 收到明细14天内可提异议；之后明显计算错误或法定权利仍可复核。

## 5. 暂缓与调整

仅就相关金额在必要期间暂缓：

- 取消、退款、拒付或支付纠纷处理中
- 合理怀疑诈骗、虚假预订、冒名或条款违反
- 需核实服务提供或账户持有人
- 法律或主管机关合法请求

告知原因、金额和解除条件，不统一扣留与调查无关的确定款项。

## 6. 税款与凭证

1. 伙伴依法申报所得和纳税。
2. 平台费VAT是公司向伙伴提供平台服务的税，与伙伴销售活动本身的所得税、VAT等不同。
3. 根据营业登记情况、税务身份、所得类型及实际供应、合同和收款关系，确认所需税务发票、发票、收据等凭证及其开具与接收主体。公司与伙伴各自履行法定凭证义务。并非所有交易都无条件按同一方向开具税务发票。 是否代扣及适用税率根据所得类型、实际交易关系等法定条件判断，不对所有未登记为经营者的个人统一适用同一税率。公司履行法定代扣、代扣税款缴纳及付款报表提交义务，并可要求必要的税务资料。伙伴的申报与纳税责任不免除公司的法定义务。
4. 伙伴应保持结算账户及税务信息准确。

## 7. 终止后结算

注销或终止资格后仍支付已完成活动的确定款项；涉及未决退款、拒付、损害赔偿或法定保存义务的金额可暂缓至确定。
