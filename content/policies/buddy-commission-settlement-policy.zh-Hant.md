# HanBuddy 夥伴傭金與結算政策

Version: 2026-09-07
Effective date: 2026-09-20

適用於夥伴提供活動產生的銷售款、平台服務費、取消退款和結算。

## 1. 費率

1. 標準不含稅平台費為實際銷售額20%；其增值稅（VAT）為不含稅費用的10%，即銷售額2%，合計扣除22%。
2. 獲批早期夥伴可適用不含稅10%的費率，VAT相當於銷售額1%，合計11%。
3. 22%和11%是費用與其VAT的合計扣除率，不是獨立費率，也不是在活動銷售額上另扣10%VAT。
4. 發佈或接受預訂前，應可在結算頁或通知中分別核對費率、VAT及合計扣除率。
5. 費率改變提前30天通知；變更前已確認預訂採用付款時費率。稅法變更則採用變更後的法定VAT稅率。

## 2. 計算依據

1. 實際銷售額指遊客折扣後實付金額中分配給該活動的金額。
2. 公司承擔的優惠可按另行促銷條件在計費前補足；夥伴承擔的優惠按折後金額計算。
3. 正常完成預訂計算如下：

   `不含稅平台費 = 實際銷售額 × 適用費率`

   `平台費VAT = 不含稅平台費 × 10%`

   `預計結算 = 實際銷售額 − 不含稅平台費 − 平台費VAT − 其他預先告知的扣款`

4. 明細分別顯示每筆銷售額、折扣、費率、不含稅費用、VAT、總扣款、退款、調整及最終支付額。

## 3. 取消退款的反映

1. 法定撤回、公司或夥伴責任、一般取消等全額退款部分不產生平台費、其VAT或夥伴報酬。
2. 遊客一般取消退50%時，以公司保留的銷售額50%計算費用、VAT及結算。
3. 不退款的一般取消或未到場按全額銷售計算。
4. 夥伴責任導致部分退款按餘額計算；全額退款不支付報酬。
5. 夥伴在開始前不足7天取消，可收實付額20%取消費；未到場除全額退款外另可收20%取消費。
6. 公司墊付退款及夥伴取消費可抵扣待結算款；不足時書面說明依據與付款方式。

## 4. 週期與支付

1. 以完成月份最後一天截止結算，原則上於次月最後一個工作日前支付至夥伴本人註冊帳戶。
2. 結算日為銀行休息日時可順延下一工作日。
3. 帳戶錯誤、未完成身份驗證、稅務資訊缺失或銀行故障可導致延遲；說明原因與必要措施。
4. 收到明細14天內可提異議；之後明顯計算錯誤或法定權利仍可復核。

## 5. 暫緩與調整

僅就相關金額在必要期間暫緩：

- 取消、退款、拒付或支付糾紛處理中
- 合理懷疑詐騙、虛假預訂、冒名或條款違反
- 需覈實服務提供或帳戶持有人
- 法律或主管機關合法請求

告知原因、金額和解除條件，不統一扣留與調查無關的確定款項。

## 6. 稅款與憑證

1. 夥伴依法申報所得和納稅。
2. 平台費VAT是公司向夥伴提供平台服務的稅，與夥伴銷售活動本身的所得稅、VAT等不同。
3. 公司出具依法必要的稅務發票、收據或結算憑證，可依法代扣、提交付款報表或要求稅務資料。
4. 夥伴應保持結算帳戶及稅務資訊準確。

## 7. 終止後結算

註銷或終止資格後仍支付已完成活動的確定款項；涉及未決退款、拒付、損害賠償或法定保存義務的金額可暫緩至確定。
