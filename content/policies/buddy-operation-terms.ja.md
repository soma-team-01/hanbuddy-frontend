# HanBuddy バディ運営規約

Version: 2026-09-07
Effective date: 2026-09-20

本規約は、活動を掲載・提供するバディに利用規約と併せて適用します。

## 第1条 資格・承認

1. 満19歳以上で、当社が求める本人確認、プロフィール、連絡先、精算、審査情報を正確に提出してください。
2. 承認は品質・収益を保証しません。安全、法令、内容、履歴の審査で補完要求・承認拒否が可能です。
3. 必要な資格、届出、許可、保険、施設使用承認はバディが確認・維持し、要求時に証明します。
4. バディは当社の従業員ではなく独立して企画・提供します。ただし実態に適用される労働・税務・消費者保護法を排除しません。

## 第2条 掲載

1. 題名、説明、写真、日程、場所、所要時間、言語、含有・除外事項、条件、定員、価格、安全事項を正確に掲載します。
2. 必須チケット、座席、飲食、設備等のうち含めるとした項目は価格に反映し、別料金は決済前に項目と概算を明示します。
3. 他人の著作物、写真、商標、個人情報を無断使用できません。
4. 当社は明らかな不正確・違法情報、高リスク、サービス趣旨に合わない活動の修正・掲載停止を求めることができます。

## 第3条 予約履行

1. 確定後は表示日時、場所、言語、内容に従って誠実に提供します。
2. 開始前に人数・準備事項を確認し、含まれるチケット、座席、食事注文、設備等を準備します。
3. 帰宅同行は明示的に含む場合を除き義務ではありません。ただし終了場所と安全な移動の基本案内を提供します。
4. サービス外決済、追加謝礼、未掲載の必須費用を要求できません。

## 第4条 変更・キャンセル

1. 日付、開始時刻、場所、主要日程、言語、含有項目の重大変更にはサービス内で同意が必要で、それまでは確定しません。
2. やむを得ない取消は可能な限り早くサービス上で行い、当社・ツーリストへ理由を伝えます。ツーリストに代行を求めてはなりません。
3. 開始7日以上前は取消料が課されないことがありますが、頻度や被害に応じ警告・表示制限が可能です。
4. 7日未満前は実決済額の20%を課せます。重病、事故、政府規制等の予見・回避困難な事情を客観的に証明した場合、当社は料金・制裁を免除できます。
5. 取消予約は全額返金され、バディ報酬は支払いません。

## 第5条 遅刻・無断欠席

1. 約束時刻前に到着し、遅延見込みは直ちにメッセージまたは登録連絡先で通知します。
2. 合意なく15分以上遅れると実決済額20%の返金があり、精算に反映します。
3. 30分以上の遅刻でツーリストが終了した場合は全額返金し、警告を課すことがあります。
4. 来場せず連絡不能の無断欠席が確認されると全額返金し、資格を直ちに停止・解除できます。さらに実決済額20%の取消料を控除または別請求できます。
5. 確認のためメッセージ、通話試行、位置・交通資料を求めることがあります。

## 第6条 安全・緊急時

1. 事前に危険、天候、経路、施設状態、注意事項を確認・案内します。
2. 専門性・資格を超える医療、運転、高リスクレジャー、許可が必要な行為を提供できません。
3. 事故、行方不明、暴力、セクハラ、健康上の緊急時は中止し、まず112・119等に連絡してから当社へ報告します。
4. 当社は救助機関ではなく現地措置を代替できませんが、受付、記録保全、アカウント保護、機関協力、事後支援を遅らせてはなりません。
5. 事故・重大問題から24時間以内に経緯と措置を提出します。緊急対応による遅延は考慮します。

## 第7条 対応・差別禁止

1. 国籍、人種、性別、性的指向、性自認、障害、宗教、年齢等を理由に不当な差別・侮辱をしてはなりません。
2. セクハラ、嫌がらせ、脅迫、ストーカー、強要、同意のない接触・撮影、私的な面会要求は禁止です。
3. 通訳・飲食注文等の含まれる支援は約束の範囲で誠実に提供します。専門資格が必要な医療・法律通訳への拡張は断り、適切な機関を案内できます。
4. 詳細は[コミュニティ・安全ポリシー](./community-safety-policy.ja.md)に従います。

## 第8条 個人情報・連絡先

1. 確定予約で得たツーリストのニックネーム、画像、人数、要望、連絡先は準備、連絡、安全、紛争処理にのみ使用します。
2. 広告、私的連絡、別サービス勧誘、名簿作成、第三者提供に使用できません。
3. 予約終了後、紛争に不要となれば別途保存した情報を直ちに削除します。
4. 漏えい・誤送信は直ちに報告し拡散防止に協力します。

## 第9条 レビュー・紛争協力

1. レビューの投稿・削除・変更を条件に利益を与えたり不利益を示唆してはなりません。
2. 取消、返金、安全、品質紛争のため合理的に求められるメッセージ、領収書、予約証明、チケット、運営資料を提出します。
3. 調整結果への異議は通知から14日以内に資料を添えて申し立てられます。

## 第10条 手数料・精算・税金

1. 報酬、手数料、返金、取消料は[手数料・精算ポリシー](./buddy-commission-settlement-policy.ja.md)に従います。
2. 通常は実売上の税抜手数料20%とVAT2%で合計22%、アーリーバディは10%とVAT1%で合計11%を控除します。
3. バディは所得申告・納税に責任を負い、当社は法定の源泉徴収・資料提出を行えます。

## 第11条 制限・資格終了

違反の程度、反復、被害、緊急性に応じ警告、非表示、新規予約制限、精算保留、一時停止、資格終了が可能です。次の場合は警告なしで緊急制限できます。

- 無断欠席、暴力、セクハラ、詐欺、重大な個人情報侵害
- 無許可活動など直ちに中止が必要な法令違反
- 生命、身体、財産への差し迫った危険

可能な限り理由と異議申立て方法を通知し、緊急性解消後は提出資料に基づき再検討します。
