# HanBuddy 伙伴运营条款

Version: 2026-10-08

本条款与服务条款一并适用于发布和提供活动的伙伴。

此前服务条款、伙伴运营条款及伙伴佣金与结算政策修订的生效日期为2026-10-06韩国标准时间（KST）。文档版本用于标识修订文本，与生效日期分别列明。费率变更的提前通知、已确认预订的保护及服务条款的修订程序仍然适用。

本次取消条款修订案的适用时间和过渡安排须另行确定。文档版本及既有修订的生效日期并非本次取消条款修订案的生效或追溯适用依据。

## 第1条 资格与批准

1. 年满19岁，准确提交公司所需身份、资料、联系方式、结算及审核信息。
2. 批准不担保质量或收入；可根据安全、合规、内容、历史要求补充或拒批。
3. 所需资质、申报、许可、保险、场地批准由伙伴核实维护，并按要求提供证明。
4. 伙伴独立规划提供活动，不是公司雇员；但不排除按实际关系适用的劳动、税务或消费者保护法律。

## 第2条 发布活动

1. 准确填写标题、说明、照片、日程、地点、时长、语言、包含与不包含项目、条件、上限、价格、安全事项。
2. 价格包括约定包含的必要门票、座位、餐饮、设备等；其他费用付款前明确项目与估计范围。
3. 不得擅用他人作品、照片、商标或个人信息。
4. 公司可要求修改或下架明显错误、违法、高风险或不符合服务宗旨的活动。

## 第3条 履约

1. 确认后按公布时间、地点、语言和内容诚信提供。
2. 开始前核对人数与准备，安排包含的门票、座位、餐食订单和设备等。
3. 未明确包含送返陪同则无此义务，但提供结束地点和安全出行基本指引。
4. 不得要求站外支付、额外酬谢或未披露的必要费用。

## 第4条 变更与取消

1. 日期、开始时间、地点、主要行程、语言、包含项目重大变更须在服务内同意，之前不视为确认。
2. 不可避免取消时尽早操作并告知公司及游客原因，不得要求游客代取消。
3. 已确认的预订必须履行。因伙伴责任取消已确认预订时，无论距离活动开始还有多久，公司都会考虑警告或限制展示等处罚。
4. 因伙伴责任取消已确认预订时，公司可收取该预订实际付款金额20%的取消费。但对于可以客观核实的不可避免原因，例如严重疾病或受伤、事故、政府限制、场地关闭或严重安全危险，以及伙伴无法控制且导致活动无法履行的天气，公司可免除费用或处罚。
5. 取消预订游客全额退款，伙伴无报酬。

## 第5条 迟到与未到场

1. 提前到达，预计延误时立即通过消息或登记方式通知。
2. 未约定迟到至少15分钟，可退游客实付额20%，反映在结算中。
3. 迟到至少30分钟游客终止时全额退款，可警告伙伴。
4. 确认未到场且无法联系，全额退款并可立即暂停或终止资格；可另扣或收实付额20%取消费。
5. 可要求消息、通话尝试、位置或交通证据核实事实及不可避免原因。

## 第6条 安全与紧急事件

1. 检查并说明危险、天气、路线、设施及注意事项。
2. 不得提供超出专业和资质的医疗、驾驶、高风险休闲或需许可的服务。
3. 事故、失踪、暴力、性骚扰、健康紧急事件应停止活动，先联系112、119等当地紧急机构，再报告公司。
4. 公司不是实时救援机构，不替代现场安全措施，但不得延迟受理、保存预订付款记录、账户保护、机构合作和后续支持。
5. 事故或重大安全问题后24小时内提交经过及措施；紧急处置导致延迟会予考虑。

## 第7条 接待与反歧视

1. 不得因国籍、种族、性别、性取向、性别认同、残疾、宗教、年龄等歧视侮辱。
2. 不得性骚扰、欺凌、威胁、跟踪、强迫、未经同意接触拍摄或要求私人会面。
3. 翻译、餐饮点单等包含支援按约提供；涉及需专业资格的医疗法律翻译，可拒绝并推荐适当机构。
4. 详见[社区与安全政策](./community-safety-policy.zh-Hans.md)。

## 第8条 个人信息与联系

1. 确定预订获得的游客昵称、图片、人数、要求、联系资料仅用于准备、联络、安全及纠纷。
2. 不得用于广告、私人联络、其他服务推广、名单编制或第三方提供。
3. 预订结束且纠纷无需保留时立即删除另存资料。
4. 发现泄露或误发立即报告并配合防止扩散。

## 第9条 评价与纠纷合作

1. 不得以评价发表、删除、修改为条件提供好处或暗示不利后果。
2. 合理提供取消、退款、安全、质量调查所需的消息、收据、预订证明、门票及运营材料。
3. 对协调结果可在通知14天内附依据提出异议。

## 第10条 费用、结算与税

1. 报酬、平台费、退款、取消费依[佣金与结算政策](./buddy-commission-settlement-policy.zh-Hans.md)。
2. 平台费按实际销售额计算，标准伙伴合计20%，获批早期伙伴合计15%。两者均包含增值税（VAT）及支付处理费，不再重复扣除。 在2026-11-30韩国标准时间（KST）前（含当日）完成伙伴入驻及申请的新申请者，经审核批准后永久适用早期伙伴费率。即使在12月或以后获批，按期完成申请者也不会因此失去资格。该日期是新申请的截止日期，不是优惠到期日。完成申请并不意味着活动自动批准。
3. 伙伴依法承担所得申报及纳税责任。公司与伙伴根据营业登记情况、税务身份、所得类型及实际交易关系履行必要凭证的开具与接收义务。公司履行法定代扣、缴纳及付款报表提交义务，不将其转嫁给伙伴。

## 第11条 限制与终止资格

按严重性、重复性、损害、紧急性可警告、隐藏活动、限制新预订、暂缓结算、暂停或终止。以下可无预警紧急限制：

- 未到场、暴力、性骚扰、诈骗、重大隐私侵害
- 无许可活动等需立即停止的违法
- 会员生命、身体、财产的紧迫危险

尽可能通知原因和申诉方式，紧急性消除后根据材料复核。
