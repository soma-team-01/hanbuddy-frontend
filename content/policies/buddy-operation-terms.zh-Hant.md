# HanBuddy 夥伴運營條款

Version: 2026-09-07
Effective date: 2026-09-20

本條款與服務條款一並適用於發佈和提供活動的夥伴。

## 第1條 資格與批准

1. 年滿19歲，準確提交公司所需身份、資料、聯繫方式、結算及審核資訊。
2. 批准不擔保質量或收入；可根據安全、合規、內容、歷史要求補充或拒批。
3. 所需資質、申報、許可、保險、場地批准由夥伴覈實維護，並按要求提供證明。
4. 夥伴獨立規劃提供活動，不是公司僱員；但不排除按實際關係適用的勞動、稅務或消費者保護法律。

## 第2條 發佈活動

1. 準確填寫標題、說明、照片、日程、地點、時長、語言、包含與不包含項目、條件、上限、價格、安全事項。
2. 價格包括約定包含的必要門票、座位、餐飲、設備等；其他費用付款前明確項目與估計範圍。
3. 不得擅用他人作品、照片、商標或個人資訊。
4. 公司可要求修改或下架明顯錯誤、違法、高風險或不符合服務宗旨的活動。

## 第3條 履約

1. 確認後按公佈時間、地點、語言和內容誠信提供。
2. 開始前核對人數與準備，安排包含的門票、座位、餐食訂單和設備等。
3. 未明確包含送返陪同則無此義務，但提供結束地點和安全出行基本指引。
4. 不得要求站外支付、額外酬謝或未披露的必要費用。

## 第4條 變更與取消

1. 日期、開始時間、地點、主要行程、語言、包含項目重大變更須在服務內同意，之前不視為確認。
2. 不可避免取消時盡早操作並告知公司及遊客原因，不得要求遊客代取消。
3. 開始前至少7天取消可能免取消費，但頻率及損害可能導致警告或降低展示。
4. 不足7天可收實付額20%取消費；客觀證明重病、事故、政府管制等難以預見或避免原因，可免除費用或處罰。
5. 取消預訂遊客全額退款，夥伴無報酬。

## 第5條 遲到與未到場

1. 提前到達，預計延誤時立即通過消息或登記方式通知。
2. 未約定遲到至少15分鐘，可退遊客實付額20%，反映在結算中。
3. 遲到至少30分鐘遊客終止時全額退款，可警告夥伴。
4. 確認未到場且無法聯繫，全額退款並可立即暫停或終止資格；可另扣或收實付額20%取消費。
5. 可要求消息、通話嘗試、位置或交通證據覈實事實及不可避免原因。

## 第6條 安全與緊急事件

1. 檢查並說明危險、天氣、路線、設施及注意事項。
2. 不得提供超出專業和資質的醫療、駕駛、高風險休閒或需許可的服務。
3. 事故、失蹤、暴力、性騷擾、健康緊急事件應停止活動，先聯繫112、119等當地緊急機構，再報告公司。
4. 公司不是實時救援機構，不替代現場安全措施，但不得延遲受理、保存預訂付款記錄、帳戶保護、機構合作和後續支持。
5. 事故或重大安全問題後24小時內提交經過及措施；緊急處置導致延遲會予考慮。

## 第7條 接待與反歧視

1. 不得因國籍、種族、性別、性取向、性別認同、殘疾、宗教、年齡等歧視侮辱。
2. 不得性騷擾、欺凌、威脅、跟蹤、強迫、未經同意接觸拍攝或要求私人會面。
3. 翻譯、餐飲點單等包含支援按約提供；涉及需專業資格的醫療法律翻譯，可拒絕並推薦適當機構。
4. 詳見[社區與安全政策](./community-safety-policy.zh-Hant.md)。

## 第8條 個人資訊與聯繫

1. 確定預訂獲得的遊客暱稱、圖片、人數、要求、聯繫資料僅用於準備、聯絡、安全及糾紛。
2. 不得用於廣告、私人聯絡、其他服務推廣、名單編制或第三方提供。
3. 預訂結束且糾紛無需保留時立即刪除另存資料。
4. 發現洩露或誤發立即報告並配合防止擴散。

## 第9條 評價與糾紛合作

1. 不得以評價發表、刪除、修改為條件提供好處或暗示不利後果。
2. 合理提供取消、退款、安全、質量調查所需的消息、收據、預訂證明、門票及運營材料。
3. 對協調結果可在通知14天內附依據提出異議。

## 第10條 費用、結算與稅

1. 報酬、平台費、退款、取消費依[傭金與結算政策](./buddy-commission-settlement-policy.zh-Hant.md)。
2. 標準不含稅20%加VAT2%，總扣22%；早期夥伴10%加VAT1%，總扣11%，均按實際銷售額。
3. 夥伴負責申報納稅；公司可依法代扣或提交資料。

## 第11條 限制與終止資格

按嚴重性、重復性、損害、緊急性可警告、隱藏活動、限制新預訂、暫緩結算、暫停或終止。以下可無預警緊急限制：

- 未到場、暴力、性騷擾、詐騙、重大隱私侵害
- 無許可活動等需立即停止的違法
- 會員生命、身體、財產的緊迫危險

盡可能通知原因和申訴方式，緊急性消除後根據材料復核。
