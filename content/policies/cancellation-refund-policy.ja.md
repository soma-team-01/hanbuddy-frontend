# HanBuddy キャンセル・返金ポリシー

Version: 2026-09-08

本ポリシーはHanBuddyで予約した活動のキャンセル、返金、日程変更、提供上の問題に適用され、利用規約の一部を構成します。詳細・決済画面にツーリストにより有利な条件がある場合、その条件を優先します。

返金は次の順で判断します。

1. 会員は契約内容の書面を受け取った日から7日以内に法定の申込み撤回を請求できます。供給がそれより遅い場合は、供給を受けた日または供給開始日から7日以内に請求できます。法令がより長い期間を保障する場合はその期間を適用します。
2. 法定撤回が認められる場合、実決済額の全額返金を優先します。
3. 法定撤回期間が経過した場合、または大韓民国「電子商取引等における消費者保護に関する法律」第17条第2項の撤回制限事由が認められる一般キャンセルには、HanBuddyの48時間・24時間基準を適用します。ただし、以下の30分無料キャンセル条件を満たす場合は全額返金を優先します。
4. バディのキャンセル・遅刻・無断欠席、説明との相違、重大な日程変更などには第3～7項を適用します。

## 1. 法定の申込み撤回権

1. 会員は契約内容の書面を受け取った日から7日以内に法定の申込み撤回を請求できます。供給がそれより遅い場合は、供給を受けた日または供給開始日から7日以内に請求できます。法令がより長い期間を保障する場合はその期間を適用します。
2. 法定撤回が認められた場合、キャンセル料なしで実決済額全額を返金します。
3. 法定撤回期間が経過した場合、または大韓民国「電子商取引等における消費者保護に関する法律」第17条第2項の撤回制限事由が認められる一般キャンセルには、HanBuddyの48時間・24時間基準を適用します。ただし、以下の30分無料キャンセル条件を満たす場合は全額返金を優先します。
4. 当社は決済前に法定撤回の可否、制限の可能性、時点別返金額、実決済額基準を分かりやすく表示し、別途同意を得ます。
5. 表示・広告・契約と異なる提供の場合、提供日から3か月以内、かつ相違を知った日または知り得た日から30日以内に撤回できます。
6. 本ポリシーは法令上の撤回、契約解除、損害賠償、紛争調整の権利を制限しません。

## 2. HanBuddyの一般キャンセル基準

決済により予約が確定してから30分以内にキャンセルを請求し、活動の予定開始時刻前である場合は、一般基準にかかわらず実決済額全額を返金します。この特典は予定開始時刻で終了します。法定撤回やその他の返金権を制限しません。

法定期間経過後、または法令上の制限事由が認められる場合の自己都合キャンセルには、詳細画面により有利な条件がない限り、予定開始時刻から次のように計算します。

| キャンセル受付時点         | 返金額         |
| -------------------------- | -------------- |
| 開始48時間以上前           | 実決済額の全額 |
| 開始24時間以上48時間未満前 | 実決済額の50%  |
| 開始24時間未満前           | 返金なし       |
| 開始後または無断欠席       | 返金なし       |

上記の表の返金制限は通常の自己都合キャンセルに適用されます。開始後も、分割可能なサービスのうち提供が開始されていない部分については法定撤回権を保障します。バディまたは当社の責任による未提供部分やその他の返金事由は、第3～7項および法令に従い全額または一部を返金します。

1. 開催地の現地時間を基準とし、韓国では韓国標準時（KST）を使用します。
2. 実決済額はクーポン、プロモーション、ポイント等の割引後に実際に承認された金額です。
3. 複数人予約は部分キャンセル未対応の間、予約全体をキャンセルします。対応する場合は取消人数分の実決済額を基準とします。
4. 受付時点はサーバーに正常記録された時点です。障害の場合、画面画像等の客観的資料を添えて直ちにサポートへ連絡してください。

## 3. バディによるキャンセル

1. バディがキャンセルした場合、該当予約の実決済額全額を返金します。
2. 日程変更や代替活動を提案できますが強制しません。同意しない場合は全額返金します。
3. バディはツーリストに代わりの取消操作を求めてはなりません。ツーリスト都合として処理された事実を確認した場合、訂正して全額返金します。
4. バディの取消料・運営措置は[バディ運営規約](./buddy-operation-terms.ja.md)と[手数料・精算ポリシー](./buddy-commission-settlement-policy.ja.md)に従います。

## 4. バディの遅刻・無断欠席

1. ツーリストは開始時刻から集合場所で連絡を試みながら待機してください。
2. 事前合意なく15分以上遅れた場合、実決済額の20%返金を請求できます。実施せず終了する場合、遅延程度と履行可能性を確認して全額返金することがあります。
3. 30分以上遅れた場合、終了して全額返金を受けられます。明示的に継続に同意した場合、遅延相応の部分返金や代替提供を協議できます。
4. 現れず連絡も取れない場合、全額返金します。
5. 交通規制や緊急事態などでも未提供分の返金権に影響しません。バディへの制裁のみ証拠に基づき別途判断できます。

## 5. 説明と異なる・正常に提供されない活動

次の場合、問題の範囲と利用程度を考慮して全額または一部を返金します。

- 場所、主要日程、言語、主要内容が告知なく著しく異なる
- 必須チケット、予約、設備、準備不足で正常実施できない
- 重大な安全リスク、バディによる重大な法令・安全ポリシー違反がある
- 含まれると表示された費用を現地で追加請求する
- その他バディの責任で全部または重要部分が提供されない

安全確保後、できるだけ早く、原則終了後72時間以内に報告してください。写真、メッセージ、領収書が迅速な確認に役立ちます。遅延のみで法定権利は消滅しませんが、遅延により確認不能となった事実は判断に影響する場合があります。

## 6. 日程・内容変更

1. 日付、開始時刻、場所、主要日程、言語、含有項目の重大変更には、サービス内でツーリストの同意が必要です。
2. 同意しない場合、違約金なしで取消し、実決済額全額の返金を受けられます。
3. ツーリストの日程変更はバディの同意と空きがある場合のみ確定します。未確定なら元の予約と一般基準を維持します。
4. 一部のみ提供された場合、提供分の価値、未提供範囲、バディの実際の事前告知費用と証拠を確認して返金額を定めます。法定撤回やバディの責任に基づく権利を不利益に制限できません。

## 7. 不可抗力

天災、政府の緊急命令、大規模交通規制、感染症の公的制限等、合理的に制御できない事情で実施不能となった場合、日程変更または取消しを案内します。取消時は未提供分の実決済額を返金します。予約に含まれない航空・宿泊・交通等は、法令上当社またはバディの責任が認められる場合を除き補償しません。

## 8. 申請・処理

1. 予約の取消・返金機能またはcontact@hanbuddy.krで申請できます。
2. 予約情報・受付時点を確認し、追加確認が必要なら資料と予想期間を案内します。
3. 法定撤回の場合、法定の起算日から3営業日以内に返金します。役務または未供給の取引では法定撤回をした日が基準です。その他本ポリシー上の返金対象キャンセルは、請求を受けた日から3営業日以内に返金します。原則として元の支払手段を使用し、カード等では遅滞なく決済事業者に請求停止または決済取消を依頼し、既に受領した代金の返還等の必要な措置を行います。
4. 当社の決済取消および必要な代金返還後も、カード明細への反映、請求額の減額、口座入金にはカード会社・銀行等の処理により追加の時間がかかる場合があります。当社は処理結果と確認可能な取引情報を案内します。この案内は法定返金義務や遅延責任を制限せず、取消依頼が失敗した場合は正常処理に向けて対応を続けます。
5. 割引分の現金返金は行いません。クーポン復元は事前告知されたプロモーション条件に従います。
6. 結果通知後3日以内にまず異議申立てができます。経過後も法定権利や正当な理由がある申請は検討します。

## 9. 不正な返金請求

偽造資料、意図的な妨害、重複補償等が合理的に疑われる場合、確認のため処理を保留できます。不正確認時は返金拒否、アカウント制限、法的措置をとることがあり、理由と異議申立て方法を通知します。
