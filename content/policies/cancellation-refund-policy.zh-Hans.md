# HanBuddy 取消与退款政策

Version: 2026-09-07
Effective date: 2026-09-20

本政策适用于HanBuddy活动的取消、退款、改期及服务问题，属于服务条款的一部分。详情或付款页提供对游客更有利的条件时，优先适用该条件。

依次判断：

1. 首先确认是否为自付款日起7天内提出的法定撤回请求。
2. 法定撤回获准时，优先退还全部实付金额。
3. 法定期间已过或法定限制理由成立的自愿取消，适用第2项48小时／24小时标准。
4. 伙伴取消、迟到、未到场、与描述不符、重大改期等其他理由适用第3至7项。

## 1. 法定撤回权

1. 会员可自付款日起7天内请求撤回。
2. 法定撤回成立时，无取消费退还全部实付金额。
3. 特定时间的预约服务临近开始或已开始提供，且大韩民国《电子商务等消费者保护法》第17条第2款限制理由获认可时，适用第2项一般规则。
4. 付款前明确显示撤回可能性、可能受限、各时点退款额及实付金额基准，并另行取得同意。
5. 活动与展示、广告或合同不符时，可在提供之日起3个月内且知道或应当知道之日起30天内撤回。
6. 不限制法律赋予的撤回、解除合同、赔偿或纠纷调解权。

## 2. HanBuddy一般取消标准

法定期间已过或法定限制事由成立时，因个人原因取消，除详情有更有利条件外，按活动计划开始时间计算：

| 取消受理时间                 | 退款          |
| ---------------------------- | ------------- |
| 开始前至少48小时             | 全部实付金额  |
| 开始前至少24小时但不足48小时 | 实付金额的50% |
| 开始前不足24小时             | 不退款        |
| 开始后或无故缺席             | 不退款        |

1. 按活动所在地时间计算；韩国活动使用韩国标准时间（KST）。
2. 实付金额是优惠券、促销、积分等折扣后经支付方式实际核准的金额。
3. 多人预订在不支持部分取消时须整单取消；支持时按取消人数对应的实付额计算。
4. 受理时间是请求成功记录到服务器的时间。故障导致无法提交时，请立即附截图等客观证据联系客服。

## 3. 伙伴取消

1. 伙伴取消时，全额退还该预订实付金额。
2. 可提供改期或替代活动，但不强制；游客拒绝时全额退款。
3. 伙伴不得要求游客代为取消。误记为游客取消时，核实后纠正并全额退款。
4. 伙伴费用与措施依照[伙伴运营条款](./buddy-operation-terms.zh-Hans.md)及[佣金与结算政策](./buddy-commission-settlement-policy.zh-Hans.md)。

## 4. 伙伴迟到或未到场

1. 游客应从开始时间起在约定地点等候并尝试联系伙伴。
2. 未事先约定迟到至少15分钟，可要求退还实付额20%；若选择不开展活动，视延迟和履行可能性可全额退款。
3. 迟到至少30分钟，可终止并全额退款；明确同意继续时，可协商相应部分退款或替代提供。
4. 未到场且无法联系时，全额退款。
5. 交通管制、紧急事件等不可避免原因不影响未提供活动的退款权；仅伙伴处罚可根据证据另行判断。

## 5. 与描述不符或未正常提供

出现下列问题时，按问题范围与使用程度全额或部分退款：

- 地点、主要行程、语言或主要内容未经告知显著改变
- 缺少必需门票、预约、设备或准备而无法正常进行
- 存在重大安全风险或伙伴严重违反法律、安全政策
- 现场另收已注明包含的费用
- 其他伙伴责任导致全部或重要部分未提供

确保安全后尽快、原则上在结束后72小时内报告。照片、消息、收据有助处理。迟报本身不消灭法定权利，但因延迟无法核实的部分可能影响退款判断。

## 6. 日程或内容变更

1. 伙伴重大改变日期、开始时间、地点、主要行程、语言或包含项目，须在服务内获游客同意。
2. 不同意重大变更者可无违约金取消并获全额退款。
3. 游客改期请求仅在伙伴同意且有空位时确认；未确认则保留原预订和一般取消规则。
4. 只提供部分行程时，核查已提供价值、未提供范围、伙伴实际承担且事前告知的费用及证据后确定退款额；不得不利限制法定撤回或伙伴责任所产生的权利。

## 7. 不可抗力

天灾、政府紧急命令、大规模交通管制、传染病官方限制等无法合理控制的原因导致不能举行时，安排改期或取消。取消则退还未提供部分的实付金额。预订外的机票、住宿、交通等附带支出不补偿，除非依法认定公司或伙伴负责。

## 8. 申请与处理

1. 可通过预订取消退款功能或contact@hanbuddy.kr申请。
2. 核查预订和取消时间，需补充时说明材料和预计处理时间。
3. 原则按原支付渠道退款；法律另有规定除外，在确认退款原因后3个工作日内开始撤销或退款程序。
4. 银行、卡组织、PayPal、Toss Payments等到账可能另需时间；公司提供可核实的撤销请求记录。
5. 优惠部分不以现金退款。优惠券恢复依付款前告知的促销条件。
6. 可在决定通知后3天内先提出异议；超过该期但基于法定权利或正当理由的请求仍予审查。

## 9. 不当退款请求

合理怀疑伪造证据、故意干扰、重复补偿等时，可暂停处理核实。确认不当行为可拒绝退款、限制账户或采取法律行动，并通知原因及申诉方式。
