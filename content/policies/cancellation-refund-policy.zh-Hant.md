# HanBuddy 取消與退款政策

Version: 2026-09-08

本政策適用於HanBuddy活動的取消、退款、改期及服務問題，屬於服務條款的一部分。詳情或付款頁提供對遊客更有利的條件時，優先適用該條件。

依次判斷：

1. 會員可自收到合約內容書面文件之日起7天內請求法定撤回。如供應時間更晚，可自收到供應或供應開始之日起7天內請求撤回；法律保障更長期限時適用該期限。
2. 法定撤回獲準時，優先退還全部實付金額。
3. 法定撤回期間已過，或大韓民國《電子商務等消費者保護法》第17條第2項規定的撤回限制事由獲認可時，一般取消適用HanBuddy的48小時／24小時標準。但滿足下述30分鐘免費取消條件時，優先全額退款。
4. 夥伴取消、遲到、未到場、與描述不符、重大改期等其他理由適用第3至7項。

## 1. 法定撤回權

1. 會員可自收到合約內容書面文件之日起7天內請求法定撤回。如供應時間更晚，可自收到供應或供應開始之日起7天內請求撤回；法律保障更長期限時適用該期限。
2. 法定撤回成立時，無取消費退還全部實付金額。
3. 法定撤回期間已過，或大韓民國《電子商務等消費者保護法》第17條第2項規定的撤回限制事由獲認可時，一般取消適用HanBuddy的48小時／24小時標準。但滿足下述30分鐘免費取消條件時，優先全額退款。
4. 付款前明確顯示撤回可能性、可能受限、各時點退款額及實付金額基準，並另行取得同意。
5. 活動與展示、廣告或合同不符時，可在提供之日起3個月內且知道或應當知道之日起30天內撤回。
6. 不限制法律賦予的撤回、解除合同、賠償或糾紛調解權。

## 2. HanBuddy一般取消標準

在付款完成並確認預訂後30分鐘內提出取消請求，且在活動預定開始時間之前，無論一般取消標準如何，均退還全部實付金額。此優惠在預定開始時間終止，不限制法定撤回及其他退款權利。

法定期間已過或法定限制事由成立時，因個人原因取消，除詳情有更有利條件外，按活動計劃開始時間計算：

| 取消受理時間                 | 退款          |
| ---------------------------- | ------------- |
| 開始前至少48小時             | 全部實付金額  |
| 開始前至少24小時但不足48小時 | 實付金額的50% |
| 開始前不足24小時             | 不退款        |
| 開始後或無故缺席             | 不退款        |

上表的退款限制適用於一般自願取消。即使活動已開始，可分割服務中尚未開始提供的部分仍保障法定撤回權。夥伴或公司責任導致未提供的部分及其他獨立退款事由，依第3至7項及相關法律全額或部分退款。

1. 按活動所在地時間計算；韓國活動使用韓國標準時間（KST）。
2. 實付金額是優惠券、促銷、積分等折扣後經支付方式實際核准的金額。
3. 多人預訂在不支持部分取消時須整單取消；支持時按取消人數對應的實付額計算。
4. 受理時間是請求成功記錄到伺服器的時間。故障導致無法提交時，請立即附截圖等客觀證據聯繫客服。

## 3. 夥伴取消

1. 夥伴取消時，全額退還該預訂實付金額。
2. 可提供改期或替代活動，但不強制；遊客拒絕時全額退款。
3. 夥伴不得要求遊客代為取消。誤記為遊客取消時，覈實後糾正並全額退款。
4. 夥伴費用與措施依照[夥伴運營條款](./buddy-operation-terms.zh-Hant.md)及[傭金與結算政策](./buddy-commission-settlement-policy.zh-Hant.md)。

## 4. 夥伴遲到或未到場

1. 遊客應從開始時間起在約定地點等候並嘗試聯繫夥伴。
2. 未事先約定遲到至少15分鐘，可要求退還實付額20%；若選擇不開展活動，視延遲和履行可能性可全額退款。
3. 遲到至少30分鐘，可終止並全額退款；明確同意繼續時，可協商相應部分退款或替代提供。
4. 未到場且無法聯繫時，全額退款。
5. 交通管制、緊急事件等不可避免原因不影響未提供活動的退款權；僅夥伴處罰可根據證據另行判斷。

## 5. 與描述不符或未正常提供

出現下列問題時，按問題範圍與使用程度全額或部分退款：

- 地點、主要行程、語言或主要內容未經告知顯著改變
- 缺少必需門票、預約、設備或準備而無法正常進行
- 存在重大安全風險或夥伴嚴重違反法律、安全政策
- 現場另收已注明包含的費用
- 其他夥伴責任導致全部或重要部分未提供

確保安全後盡快、原則上在結束後72小時內報告。照片、消息、收據有助處理。遲報本身不消滅法定權利，但因延遲無法覈實的部分可能影響退款判斷。

## 6. 日程或內容變更

1. 夥伴重大改變日期、開始時間、地點、主要行程、語言或包含項目，須在服務內獲遊客同意。
2. 不同意重大變更者可無違約金取消並獲全額退款。
3. 遊客改期請求僅在夥伴同意且有空位時確認；未確認則保留原預訂和一般取消規則。
4. 只提供部分行程時，核查已提供價值、未提供範圍、夥伴實際承擔且事前告知的費用及證據後確定退款額；不得不利限制法定撤回或夥伴責任所產生的權利。

## 7. 不可抗力

天災、政府緊急命令、大規模交通管制、傳染病官方限制等無法合理控制的原因導致不能舉行時，安排改期或取消。取消則退還未提供部分的實付金額。預訂外的機票、住宿、交通等附帶支出不補償，除非依法認定公司或夥伴負責。

## 8. 申請與處理

1. 可通過預訂取消退款功能或contact@hanbuddy.kr申請。
2. 核查預訂和取消時間，需補充時說明材料和預計處理時間。
3. 法定撤回退款在法定起算日起3個工作日內退款；服務或尚未供應的交易以行使法定撤回之日為準。其他依本政策可退款的取消，自收到請求之日起3個工作日內退款。原則上循原付款方式退回，信用卡等付款將及時要求支付機構停止請款或撤銷支付，並採取退還已收款項等必要措施。
4. 公司撤銷支付並完成必要的款項返還後，信用卡帳單更新、應付金額扣減或帳戶入帳仍可能因發卡行、銀行等機構流程而需要額外時間。公司提供處理結果及可核實的交易資訊。本說明不限制公司的法定退款義務或延遲責任；撤銷請求失敗時將繼續跟進至正常處理。
5. 優惠部分不以現金退款。優惠券恢復依付款前告知的促銷條件。
6. 可在決定通知後3天內先提出異議；超過該期但基於法定權利或正當理由的請求仍予審查。

## 9. 不當退款請求

合理懷疑偽造證據、故意干擾、重復補償等時，可暫停處理覈實。確認不當行為可拒絕退款、限制帳戶或採取法律行動，並通知原因及申訴方式。
