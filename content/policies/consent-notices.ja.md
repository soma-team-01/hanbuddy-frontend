# HanBuddy 同意事項

Version: 2026-09-07
Effective date: 2026-09-20

登録時の同意内容です。必須と任意を区別し、任意の同意を拒否しても基本機能を利用できます。

## 1. 共通の会員登録

### [必須] 満19歳以上の確認

私は満19歳以上であり、HanBuddyは成人のみが登録・利用できることを確認します。

### [必須] 利用規約への同意

[HanBuddy利用規約](./terms-of-service.ja.md)の全文を確認し、同意します。

### [必須] 個人情報の収集・利用

| 項目           | 内容                                                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 収集情報       | 共通：Google識別子、メール、氏名、画像、ニックネーム、国籍、生年月日。ツーリスト：希望連絡手段、IDまたは電話番号。バディ：審査・運営連絡用電話番号。 |
| 目的           | 共通：登録、ログイン、本人・年齢確認、プロフィール、セキュリティ、サポート。ツーリスト：予約当事者の連絡。バディ：審査、結果通知、運営連絡。         |
| 保有期間       | 退会まで。ただし契約、決済、紛争、同意記録は法定期間分離保管。                                                                                       |
| 拒否権・不利益 | 拒否できますが、必須情報のため登録・利用が困難になります。                                                                                           |

上記に同意します。詳細は[プライバシーポリシー](./privacy-policy.ja.md)をご覧ください。

### [任意] マーケティング情報

| 項目           | 内容                                     |
| -------------- | ---------------------------------------- |
| 収集・利用情報 | メール、ニックネーム、利用・予約履歴     |
| 目的           | イベント、特典、新規活動、プロモーション |
| 保有期間       | 同意撤回または退会まで                   |
| 拒否権・不利益 | 拒否しても基本機能を利用できます。       |

メールによる案内に同意します。設定やメールの配信停止からいつでも撤回できます。

## 2. バディ申請

共通事項に加え、以下の各同意を取得します。

### [必須] バディ運営規約

[バディ運営規約](./buddy-operation-terms.ja.md)を確認し、情報の正確性、予約履行、安全、個人情報保護、コミュニティ基準の遵守に同意します。

### [必須] 手数料・精算ポリシー

[手数料・精算ポリシー](./buddy-commission-settlement-policy.ja.md)を確認し、通常は実売上の税抜手数料20%とVAT2%の合計22%、アーリーバディは10%とVAT1%の合計11%が控除されることを確認します。表示された精算周期と取消・返金・チャージバックの反映基準にも同意します。

## 3. 予約申請・決済

### [必須] キャンセル・返金ポリシー

決済日から7日以内は法令に基づく撤回を請求でき、法定撤回が認められる場合は法令が優先することを確認します。

法定期間経過後または法令上の制限事由が認められる場合、予定開始時刻に基づく次の一般基準を確認します。

| 受付時点                   | 返金額        |
| -------------------------- | ------------- |
| 開始48時間以上前           | 実決済額全額  |
| 開始24時間以上48時間未満前 | 実決済額の50% |
| 開始24時間未満前           | 返金なし      |
| 開始後・無断欠席           | 返金なし      |

[キャンセル・返金ポリシー](./cancellation-refund-policy.ja.md)全文を確認し、同意します。

決済待ちの申請から支払いを再開する場合も、決済直前に同じ案内を再確認して必須同意します。
