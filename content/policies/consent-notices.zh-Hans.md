# HanBuddy 同意事项

Version: 2026-09-07
Effective date: 2026-09-20

以下说明注册同意，区分必选与可选；拒绝可选项目不影响基本功能。

## 1. 通用注册

### [必选] 年满19岁确认

本人确认年满19岁，HanBuddy仅限成年人注册使用。

### [必选] 服务条款

已阅读[服务条款](./terms-of-service.zh-Hans.md)全文并同意。

### [必选] 个人信息收集使用

| 项目         | 内容                                                                                                                                   |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 收集信息     | 通用：Google账户标识、邮箱、姓名、头像、昵称、国籍、出生日期。游客：首选联系方式、联系ID或电话号码。伙伴：审核及运营联系所需电话号码。 |
| 目的         | 通用：注册、登录、身份年龄验证、资料、安全、客服。游客：预订双方联系。伙伴：审核、结果及运营通知。                                     |
| 保存         | 至注销；合同、付款、纠纷、同意记录按法定期间分开保存。                                                                                 |
| 拒绝权及后果 | 可拒绝，但因属必要信息，注册使用将有困难。                                                                                             |

同意上述收集使用，详情见[隐私政策](./privacy-policy.zh-Hans.md)。

### [可选] 营销信息

| 项目         | 内容                         |
| ------------ | ---------------------------- |
| 收集使用     | 邮箱、昵称、使用及预订历史   |
| 目的         | 活动、优惠、新项目、促销通知 |
| 保存         | 至撤回或注销                 |
| 拒绝权及后果 | 拒绝仍可使用基本功能。       |

同意接收营销邮件，可随时在账户设置或邮件退订中撤回。

## 2. 伙伴申请

在通用同意外分别取得：

### [必选] 伙伴运营条款

阅读[运营条款](./buddy-operation-terms.zh-Hans.md)，同意信息准确、履行预订、安全措施、隐私保护和社区标准。

### [必选] 佣金与结算政策

阅读[佣金与结算政策](./buddy-commission-settlement-policy.zh-Hans.md)，确认标准不含税20%加VAT2%合计22%，早期10%加VAT1%合计11%，从实际销售额扣除。同意所显示的结算周期及取消、退款、拒付处理规则。

## 3. 预订申请与付款

### [必选] 取消与退款政策

确认付款日起7天内可依法请求撤回，法定撤回成立时优先适用相关法律。

法定期限后或法定限制成立时，按计划开始时间适用：

| 取消时间                     | 退款       |
| ---------------------------- | ---------- |
| 开始前至少48小时             | 全部实付额 |
| 开始前至少24小时但不足48小时 | 实付额50%  |
| 开始前不足24小时             | 不退款     |
| 开始后或无故缺席             | 不退款     |

已阅读[取消与退款政策](./cancellation-refund-policy.zh-Hans.md)全文并同意。

待付款后从我的申请继续支付时，也须在付款前重新确认相同说明并必选同意。
