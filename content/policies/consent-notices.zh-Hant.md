# HanBuddy 同意事項

Version: 2026-09-07
Effective date: 2026-09-20

以下說明註冊同意，區分必選與可選；拒絕可選項目不影響基本功能。

## 1. 通用註冊

### [必選] 年滿19歲確認

本人確認年滿19歲，HanBuddy僅限成年人註冊使用。

### [必選] 服務條款

已閱讀[服務條款](./terms-of-service.zh-Hant.md)全文並同意。

### [必選] 個人資訊收集使用

| 項目         | 內容                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 收集資訊     | 通用：Google帳戶標識、電子郵件、姓名、個人照片、暱稱、國籍、出生日期。遊客：首選聯繫方式、聯繫ID或電話號碼。夥伴：審核及運營聯繫所需電話號碼。 |
| 目的         | 通用：註冊、登錄、身份年齡驗證、資料、安全、客服。遊客：預訂雙方聯繫。夥伴：審核、結果及運營通知。                                             |
| 保存         | 至註銷；合同、付款、糾紛、同意記錄按法定期間分開保存。                                                                                         |
| 拒絕權及後果 | 可拒絕，但因屬必要資訊，註冊使用將有困難。                                                                                                     |

同意上述收集使用，詳情見[隱私政策](./privacy-policy.zh-Hant.md)。

### [可選] 營銷資訊

| 項目         | 內容                           |
| ------------ | ------------------------------ |
| 收集使用     | 電子郵件、暱稱、使用及預訂歷史 |
| 目的         | 活動、優惠、新項目、促銷通知   |
| 保存         | 至撤回或註銷                   |
| 拒絕權及後果 | 拒絕仍可使用基本功能。         |

同意接收營銷郵件，可隨時在帳戶設置或郵件退訂中撤回。

## 2. 夥伴申請

在通用同意外分別取得：

### [必選] 夥伴運營條款

閱讀[運營條款](./buddy-operation-terms.zh-Hant.md)，同意資訊準確、履行預訂、安全措施、隱私保護和社區標準。

### [必選] 傭金與結算政策

閱讀[傭金與結算政策](./buddy-commission-settlement-policy.zh-Hant.md)，確認標準不含稅20%加VAT2%合計22%，早期10%加VAT1%合計11%，從實際銷售額扣除。同意所顯示的結算週期及取消、退款、拒付處理規則。

## 3. 預訂申請與付款

### [必選] 取消與退款政策

確認付款日起7天內可依法請求撤回，法定撤回成立時優先適用相關法律。

法定期限後或法定限製成立時，按計劃開始時間適用：

| 取消時間                     | 退款       |
| ---------------------------- | ---------- |
| 開始前至少48小時             | 全部實付額 |
| 開始前至少24小時但不足48小時 | 實付額50%  |
| 開始前不足24小時             | 不退款     |
| 開始後或無故缺席             | 不退款     |

已閱讀[取消與退款政策](./cancellation-refund-policy.zh-Hant.md)全文並同意。

待付款後從我的申請繼續支付時，也須在付款前重新確認相同說明並必選同意。
