# HanBuddy プライバシーポリシー

Version: 2026-09-07
Effective date: 2026-09-20

Zero One（以下「当社」）は個人情報を重視し、大韓民国の個人情報保護法等を遵守します。本方針は処理する情報・目的、提供・委託先、および利用者の権利を説明します。

## 1. 処理する個人情報

本サービスで次の情報を処理することがあります。

| 区分                 | 情報                                                                         | 収集方法                           |
| -------------------- | ---------------------------------------------------------------------------- | ---------------------------------- |
| Googleログイン       | Google識別子、メール、氏名、プロフィール画像                                 | 利用者の選択時にGoogleから取得     |
| 共通プロフィール     | ニックネーム、国籍、生年月日、画像                                           | 登録・編集画面で入力               |
| ツーリスト連絡先     | 希望連絡手段、IDまたは電話番号                                               | 登録・編集画面で入力               |
| バディ申請・運営     | 電話番号、申請内容、紹介、経験・資格証明、活動情報・画像、精算情報           | バディの提出または審査・精算で生成 |
| 予約・活動           | 予約番号、活動・日時・人数、要望、取消・返金、メッセージ、レビュー           | 予約・活動・サポートで生成         |
| 決済                 | 注文番号、額、通貨、割引、手段、取引ID、承認・取消・返金状態                 | Toss Payments、PayPal等から取得    |
| サポート・安全       | 問合せ、通報対象、メッセージ、写真・動画・領収書・通話試行等の提出資料、結果 | 提出または紛争処理で生成           |
| 利用記録             | 接続時刻、IP、ブラウザ・端末、Cookie、履歴、エラー・安全ログ                 | 自動生成                           |
| 任意のマーケティング | メール、ニックネーム、同意・撤回記録                                         | 任意同意                           |

完全なカード番号、カード・決済口座のパスワードは直接保存しません。機微情報・住民登録番号は法的根拠または別途明示的同意がない限り処理しません。

## 2. 目的

1. 登録、本人・年齢確認、ログイン、安全、不正利用防止
2. バディ審査、掲載・表示・運営・精算
3. 検索、予約確定、決済、取消、返金、当事者間連絡
4. メッセージ、通知、翻訳、地図・住所検索
5. 問合せ、安全通報、紛争調整、救済、法的義務
6. 障害分析、安全、品質改善、統計
7. 任意同意に基づくイベント・販促案内

## 3. 保有・利用期間

不要となった情報は速やかに破棄します。ただし法令に従い次を保存します。

| 記録                       | 期間                                     | 根拠・目的                                 |
| -------------------------- | ---------------------------------------- | ------------------------------------------ |
| 契約・申込み撤回           | 5年                                      | 電子商取引等における消費者保護に関する法律 |
| 決済・商品やサービスの提供 | 5年                                      | 同法                                       |
| 消費者の苦情・紛争         | 3年                                      | 同法                                       |
| 表示・広告                 | 6か月                                    | 同法                                       |
| 同意・規約受諾             | 退会・撤回後も関連取引・紛争保存期間まで | 同意証明・紛争対応                         |

その他のプロフィール・アカウント情報は原則退会まで、販促情報は撤回または退会まで処理します。進行中の予約・精算・紛争については、処理と法定保存期間の終了まで必要情報のみ分離保管します。

## 4. 第三者提供

同意または法的根拠なく第三者提供しません。予約確定後、ツーリストの同意範囲で当該バディへ次を提供します。

| 提供先           | 目的                                       | 情報                                             | 保有・利用                                           |
| ---------------- | ------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| 予約活動のバディ | 本人確認、準備、日時・場所連絡、安全、紛争 | ニックネーム、画像、人数、要望、連絡手段・連絡先 | 活動・紛争目的達成まで。別途保存情報は速やかに削除。 |

ニックネームと画像はバディ・ツーリストとも同様に公開します。本人が投稿した活動・レビューも利用者に表示される場合があります。バディの審査用電話番号等はツーリストや一般利用者に公開・提供しません。

提供を拒否できますが、履行に必要な連絡ができないため予約できません。生命・身体の緊急保護、適法な捜査要請など法令上許される場合は同意なしに提供できます。

## 5. 委託

円滑な提供のため次を委託でき、契約で保護、目的外利用禁止、安全、再委託、監督を管理します。

| 委託先                                  | 業務                                             |
| --------------------------------------- | ------------------------------------------------ |
| Amazon Web Services, Inc.および関連会社 | サーバー、DB、ファイル保存、安全、運用、翻訳基盤 |
| Toss Payments Co., Ltd.                 | 国内決済の承認・取消・返金、不正防止             |
| PayPalの契約法人                        | 海外決済の承認・取消・返金、不正防止             |
| Google LLC                              | ログイン、地図・住所検索                         |

変更は本方針で公表します。独自の法的義務で処理する決済事業者には、その方針も適用されることがあります。

## 6. 国外移転

Googleログイン・地図、PayPal利用時に次の移転があり得ます。

| 移転先・連絡先                       | 国                                   | 情報                                                                 | 目的                                     | 時期・方法               | 保有期間              |
| ------------------------------------ | ------------------------------------ | -------------------------------------------------------------------- | ---------------------------------------- | ------------------------ | --------------------- |
| Google LLC（Google Privacy Inquiry） | 米国およびGoogleデータセンター所在国 | ログイン要求・応答、識別子、メール、氏名、画像、住所検索語、技術ログ | ログイン、地図、住所検索、安全           | 機能利用時に暗号化送信   | Google方針と第3項     |
| PayPal Pte. Ltd.（PayPal Privacy）   | シンガポールおよびグループ運営国     | メール、注文番号、金額・通貨、決済手段・状態、IP・端末               | 決済承認・取消・返金、本人確認、不正防止 | PayPal決済時に暗号化送信 | PayPal法定期間と第3項 |

拒否できます。Googleの移転拒否は現行の登録・ログインを困難にし、PayPalの拒否はその決済を利用できなくします。国内決済等の代替手段があれば利用できます。問合せ・拒否はcontact@hanbuddy.krへご連絡ください。

## 7. 破棄

1. 期間終了・目的達成後、速やかに破棄します。
2. 法定保存情報は分離保管し、所定目的以外に使用しません。
3. 電子情報は復旧困難な方法で削除し、紙は裁断・焼却します。

## 8. 利用者・法定代理人の権利

1. 閲覧、訂正、削除、処理停止、同意撤回、移転要求等の法定権利を行使できます。
2. プロフィール・設定またはcontact@hanbuddy.krで請求できます。
3. 本人・正当な代理人を確認し法定期間内に対応・通知します。制限事由があれば理由・不服申立て方法を案内します。
4. 満19歳未満は登録できません。誤収集が判明した場合、確認後速やかに削除します。

## 9. 安全措置

最小限のアクセス権、認証・アクセス制御、転送・保存時の暗号化、アクセス記録の保存・点検、脆弱性管理、バックアップ、従業員教育等の技術的・管理的措置を行います。

## 10. Cookie等

1. ログイン維持、言語、安全、改善にCookie等を使用します。
2. 必須Cookieは提供に必要です。分析・広告Cookie導入時には目的、提供者、期間を別途通知し必要な同意を得ます。
3. ブラウザで削除・拒否できますが、必須Cookie拒否時はログイン等が使えない場合があります。

## 11. 自動化された決定

現在、権利・義務に重大な影響を与える決定を完全自動では行っていません。導入時は基準、影響、拒否・説明要求方法を公表します。
