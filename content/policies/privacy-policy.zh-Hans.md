# HanBuddy 隐私政策

Version: 2026-09-07
Effective date: 2026-09-20

Zero One（“公司”）重视用户个人信息，遵守大韩民国个人信息保护法等法律。本政策解释处理的信息、原因、提供或委托对象以及用户权利。

## 1. 处理的个人信息

使用服务时可能处理：

| 类别         | 信息                                                   | 来源                        |
| ------------ | ------------------------------------------------------ | --------------------------- |
| Google登录   | 账户标识、邮箱、姓名、头像                             | 选择Google登录时取得        |
| 通用资料     | 昵称、国籍、出生日期、头像                             | 注册及编辑输入              |
| 游客联系资料 | 首选联系方式、联系ID或电话                             | 注册及编辑输入              |
| 伙伴申请运营 | 电话、申请、介绍、经历资质证明、活动信息图片、结算资料 | 伙伴提交或审核结算生成      |
| 预订活动     | 预订号、活动时间人数、要求、取消退款、双方消息、评价   | 预订活动客服生成            |
| 支付         | 订单、金额、币种、优惠、方式、交易ID、核准取消退款状态 | Toss Payments、PayPal等提供 |
| 客服安全     | 咨询、举报对象、提交的消息照片视频收据通话尝试等、结果 | 用户提交或纠纷生成          |
| 使用         | 时间、IP、浏览器设备、Cookie、历史、错误安全日志       | 自动生成                    |
| 可选营销     | 邮箱、昵称、同意撤回记录                               | 自愿同意                    |

公司不直接保存完整卡号、银行卡密码或支付账户密码。敏感信息或居民登记号码仅在有法定依据或单独明确同意时处理。

## 2. 目的

1. 注册、身份年龄核验、登录、安全、防滥用。
2. 伙伴资格审核、活动发布展示运营、结算。
3. 搜索、确认预订、付款、取消退款、双方联系。
4. 消息、通知、翻译、地图地址搜索。
5. 客服、安全举报、纠纷调解、救济、法律义务。
6. 故障分析、安全、质量改善、统计。
7. 自愿同意后的活动促销信息。

## 3. 保存与使用期限

不再需要时及时销毁，但依法保存：

| 记录               | 期限                               | 依据目的               |
| ------------------ | ---------------------------------- | ---------------------- |
| 合同、法定撤回     | 5年                                | 电子商务等消费者保护法 |
| 支付、商品服务提供 | 5年                                | 同法                   |
| 消费者投诉纠纷     | 3年                                | 同法                   |
| 展示广告           | 6个月                              | 同法                   |
| 同意与条款接受     | 注销或撤回后至相关交易纠纷保存期满 | 证明同意与纠纷处理     |

其他账户资料原则保存至注销，营销信息至撤回或注销。未决预订、结算、纠纷所需资料单独保存至处理与法定期限结束。

## 4. 第三方提供

除同意或法律依据，不向第三方提供。确认预订后，在游客同意范围内向对应伙伴提供：

| 接收者       | 目的                                       | 信息                                               | 保存使用                                   |
| ------------ | ------------------------------------------ | -------------------------------------------------- | ------------------------------------------ |
| 预订活动伙伴 | 参加者确认、准备、时间地点联系、安全、纠纷 | 游客昵称、头像、人数、要求、首选联系方法与联系资料 | 至活动与纠纷目的完成；另存资料须及时删除。 |

伙伴和游客的昵称头像均以相同方式公开；自行发布的活动评价等亦可展示。伙伴审核提交的电话等联系资料不向游客或一般用户公开提供。

游客可拒绝，但因无法进行必要联络而不能预订。紧急保护生命身体或合法调查等法律允许情况可不经同意提供。

## 5. 委托处理

可委托以下专业服务，并通过合同管理隐私保护、禁止超目的使用、安全、转委托、监督：

| 受托方                              | 工作                                         |
| ----------------------------------- | -------------------------------------------- |
| Amazon Web Services, Inc.及关联公司 | 服务器数据库文件存储、安全运营、翻译基础设施 |
| Toss Payments Co., Ltd.             | 韩国境内支付核准取消退款与防欺诈             |
| PayPal相关签约实体                  | 跨境支付核准取消退款与防欺诈                 |
| Google LLC                          | 登录、地图地址搜索                           |

变更通过本政策公开。支付机构因自身法律义务独立处理的数据也可能适用其隐私政策。

## 6. 跨境传输

选择Google登录、地图或PayPal时可能发生：

| 接收方与联系方式                     | 国家                       | 信息                                                 | 目的                               | 时间方式             | 保存                  |
| ------------------------------------ | -------------------------- | ---------------------------------------------------- | ---------------------------------- | -------------------- | --------------------- |
| Google LLC（Google Privacy Inquiry） | 美国及Google数据中心所在国 | 登录请求响应、标识、邮箱姓名头像、地址查询、技术日志 | 登录地图地址查询安全               | 使用功能时加密传输   | Google政策及第3项     |
| PayPal Pte. Ltd.（PayPal Privacy）   | 新加坡及PayPal集团运营国   | 邮箱订单、金额币种、支付方式交易状态、IP设备         | 支付核准取消退款、身份验证、防欺诈 | PayPal支付时加密传输 | PayPal法定期间及第3项 |

可拒绝；拒绝Google传输可能无法通过当前方式注册登录，拒绝PayPal传输则不能使用该支付。若提供国内支付等替代方式，可使用。咨询或拒绝联系contact@hanbuddy.kr。

## 7. 销毁

1. 期限结束或目的完成即及时销毁。
2. 法定保存数据单独存放，仅用于规定目的。
3. 电子文件以难恢复方式删除，纸张粉碎或焚毁。

## 8. 用户与法定代理人权利

1. 可依法查阅、更正、删除、暂停处理、撤回同意、请求数据传输等。
2. 可通过资料编辑、设置或contact@hanbuddy.kr请求。
3. 核实本人或合法代理人后，在法定期间处理并告知结果；如受法律限制则告知原因与异议方式。
4. 不允许未满19岁注册。误收未成年人信息时核实后及时删除。

## 9. 安全保障

采取最少权限、认证访问控制、传输存储加密、访问记录保存审查、漏洞管理、备份、员工培训等技术与管理措施。

## 10. Cookie与类似技术

1. 用于保持登录、语言设置、安全、服务改善。
2. 必要Cookie用于提供服务；引入分析广告Cookie时另行说明目的、提供者、期限并取得必要同意。
3. 可在浏览器删除屏蔽；屏蔽必要Cookie可能无法登录等。

## 11. 自动化决定

目前不完全以自动方式做出重大影响用户权利义务的决定。若引入，将公开标准、影响及拒绝、解释请求方式。
