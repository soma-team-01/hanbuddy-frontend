# HanBuddy 隱私政策

Version: 2026-09-07
Effective date: 2026-09-20

Zero One（“公司”）重視使用者個人資訊，遵守大韓民國個人資訊保護法等法律。本政策解釋處理的資訊、原因、提供或委託對象以及使用者權利。

## 1. 處理的個人資訊

使用服務時可能處理：

| 類別         | 資訊                                                   | 來源                        |
| ------------ | ------------------------------------------------------ | --------------------------- |
| Google登錄   | 帳戶標識、電子郵件、姓名、個人照片                     | 選擇Google登錄時取得        |
| 通用資料     | 暱稱、國籍、出生日期、個人照片                         | 註冊及編輯輸入              |
| 遊客聯繫資料 | 首選聯繫方式、聯繫ID或電話                             | 註冊及編輯輸入              |
| 夥伴申請運營 | 電話、申請、介紹、經歷資質證明、活動資訊圖片、結算資料 | 夥伴提交或審核結算生成      |
| 預訂活動     | 預訂號、活動時間人數、要求、取消退款、雙方消息、評價   | 預訂活動客服生成            |
| 支付         | 訂單、金額、幣種、優惠、方式、交易ID、核准取消退款狀態 | Toss Payments、PayPal等提供 |
| 客服安全     | 咨詢、舉報對象、提交的消息照片影片收據通話嘗試等、結果 | 使用者提交或糾紛生成        |
| 使用         | 時間、IP、瀏覽器設備、Cookie、歷史、錯誤安全日誌       | 自動生成                    |
| 可選營銷     | 電子郵件、暱稱、同意撤回記錄                           | 自願同意                    |

公司不直接保存完整卡號、銀行卡密碼或支付帳戶密碼。敏感資訊或居民登記號碼僅在有法定依據或單獨明確同意時處理。

## 2. 目的

1. 註冊、身份年齡核驗、登錄、安全、防濫用。
2. 夥伴資格審核、活動發佈展示運營、結算。
3. 搜索、確認預訂、付款、取消退款、雙方聯繫。
4. 消息、通知、翻譯、地圖地址搜索。
5. 客服、安全舉報、糾紛調解、救濟、法律義務。
6. 故障分析、安全、質量改善、統計。
7. 自願同意後的活動促銷資訊。

## 3. 保存與使用期限

不再需要時及時銷毀，但依法保存：

| 記錄               | 期限                               | 依據目的               |
| ------------------ | ---------------------------------- | ---------------------- |
| 合同、法定撤回     | 5年                                | 電子商務等消費者保護法 |
| 支付、商品服務提供 | 5年                                | 同法                   |
| 消費者投訴糾紛     | 3年                                | 同法                   |
| 展示廣告           | 6個月                              | 同法                   |
| 同意與條款接受     | 註銷或撤回後至相關交易糾紛保存期滿 | 證明同意與糾紛處理     |

其他帳戶資料原則保存至註銷，營銷資訊至撤回或註銷。未決預訂、結算、糾紛所需資料單獨保存至處理與法定期限結束。

## 4. 第三方提供

除同意或法律依據，不向第三方提供。確認預訂後，在遊客同意範圍內向對應夥伴提供：

| 接收者       | 目的                                       | 資訊                                                   | 保存使用                                   |
| ------------ | ------------------------------------------ | ------------------------------------------------------ | ------------------------------------------ |
| 預訂活動夥伴 | 參加者確認、準備、時間地點聯繫、安全、糾紛 | 遊客暱稱、個人照片、人數、要求、首選聯繫方法與聯繫資料 | 至活動與糾紛目的完成；另存資料須及時刪除。 |

夥伴和遊客的暱稱個人照片均以相同方式公開；自行發佈的活動評價等亦可展示。夥伴審核提交的電話等聯繫資料不向遊客或一般使用者公開提供。

遊客可拒絕，但因無法進行必要聯絡而不能預訂。緊急保護生命身體或合法調查等法律允許情況可不經同意提供。

可委託以下專業服務，並通過合同管理隱私保護、禁止超目的使用、安全、轉委託、監督：

| 受託方                              | 工作                                         |
| ----------------------------------- | -------------------------------------------- |
| Amazon Web Services, Inc.及關聯公司 | 伺服器數據庫文件存儲、安全運營、翻譯基礎設施 |
| Toss Payments Co., Ltd.             | 韓國境內支付核准取消退款與防欺詐             |
| PayPal相關簽約實體                  | 跨境支付核准取消退款與防欺詐                 |
| Google LLC                          | 登錄、地圖地址搜索                           |

變更通過本政策公開。支付機構因自身法律義務獨立處理的數據也可能適用其隱私政策。

## 6. 跨境傳輸

選擇Google登錄、地圖或PayPal時可能發生：

| 接收方與聯繫方式                     | 國家                       | 資訊                                                         | 目的                               | 時間方式             | 保存                  |
| ------------------------------------ | -------------------------- | ------------------------------------------------------------ | ---------------------------------- | -------------------- | --------------------- |
| Google LLC（Google Privacy Inquiry） | 美國及Google數據中心所在國 | 登錄請求響應、標識、電子郵件姓名個人照片、地址查詢、技術日誌 | 登錄地圖地址查詢安全               | 使用功能時加密傳輸   | Google政策及第3項     |
| PayPal Pte. Ltd.（PayPal Privacy）   | 新加坡及PayPal集團運營國   | 電子郵件訂單、金額幣種、支付方式交易狀態、IP設備             | 支付核准取消退款、身份驗證、防欺詐 | PayPal支付時加密傳輸 | PayPal法定期間及第3項 |

可拒絕；拒絕Google傳輸可能無法通過當前方式註冊登錄，拒絕PayPal傳輸則不能使用該支付。若提供國內支付等替代方式，可使用。咨詢或拒絕聯繫contact@hanbuddy.kr。

## 7. 銷毀

1. 期限結束或目的完成即及時銷毀。
2. 法定保存數據單獨存放，僅用於規定目的。
3. 電子文件以難恢復方式刪除，紙張粉碎或焚毀。

## 8. 使用者與法定代理人權利

1. 可依法查閱、更正、刪除、暫停處理、撤回同意、請求數據傳輸等。
2. 可通過資料編輯、設置或contact@hanbuddy.kr請求。
3. 覈實本人或合法代理人後，在法定期間處理並告知結果；如受法律限制則告知原因與異議方式。
4. 不允許未滿19歲註冊。誤收未成年人資訊時覈實後及時刪除。

## 9. 安全保障

採取最少權限、認證訪問控制、傳輸存儲加密、訪問記錄保存審查、漏洞管理、備份、員工培訓等技術與管理措施。

## 10. Cookie與類似技術

1. 用於保持登錄、語言設置、安全、服務改善。
2. 必要Cookie用於提供服務；引入分析廣告Cookie時另行說明目的、提供者、期限並取得必要同意。
3. 可在瀏覽器刪除屏蔽；屏蔽必要Cookie可能無法登錄等。

## 11. 自動化決定

目前不完全以自動方式做出重大影響使用者權利義務的決定。若引入，將公開標準、影響及拒絕、解釋請求方式。
