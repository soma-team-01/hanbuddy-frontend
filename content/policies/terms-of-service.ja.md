# HanBuddy 利用規約

Version: 2026-09-07
Effective date: 2026-09-20

## 第1条 目的

本規約は、Zero One（以下「当社」）が運営するHanBuddyのウェブサイトおよび関連サービス（以下「本サービス」）について、当社と会員の権利、義務、責任ならびに利用条件と手続きを定めます。

## 第2条 定義

1. 「会員」とは、本規約に同意してアカウントを作成した方です。
2. 「ツーリスト」とは、バディが掲載したアクティビティを検索、予約、決済する会員です。
3. 「バディ」とは、当社の審査・承認を経てアクティビティを掲載し、ツーリストに提供する会員です。
4. 「アクティビティ」とは、バディの定める日程・内容に従って提供される現地体験、同行、案内および付随サービスです。
5. 「予約」とは、アクティビティ、日程、人数、金額を確認し、決済を完了して提供契約を締結する行為です。
6. 「コンテンツ」とは、会員が投稿・送信する文章、写真、動画、レビュー、メッセージなどの一切の資料です。

## 第3条 規約の掲示・変更

1. 当社は、本規約、商号、代表者、住所、連絡先、事業者登録番号、通信販売業の届出事項を確認しやすい場所に掲示します。
2. 法令に反しない範囲で規約を変更できます。不利益または重要な変更は施行日と理由を明示して30日前から、その他の変更は7日前から告知します。
3. 会員の権利・義務に重大な影響を与える変更について、法令上必要な場合は別途同意を得ます。
4. 規定のない事項は、関連法令、個別ポリシーおよび一般的な商慣習に従います。

## 第4条 会員資格・登録

1. 登録・利用は満19歳以上に限ります。登録・予約時には正確な情報を提供してください。
2. 本人名義のGoogleアカウントなど当社の対応する認証手段を使用し、アカウントの譲渡、貸与、共有はできません。
3. 次の場合、登録を拒否し、または利用を制限することがあります。
   - 他人の情報や虚偽の情報を使用した場合
   - 満19歳未満の場合
   - 過去に重大な規約違反で制限された場合
   - 法令や公序良俗に反する目的の場合
4. バディによる掲載には別途審査・承認が必要です。会員登録だけで提供権限は付与されません。

## 第5条 契約当事者・当社の役割

1. 当社と会員との間に本サービスの利用契約が成立します。
2. 個別の提供契約は原則として掲載バディと予約ツーリストの間に成立します。詳細・決済画面には提供バディと主要な取引条件を表示します。
3. 当社は掲載、検索、予約、決済手段への接続、自動通知、サポート、紛争調整を提供します。代金を受領する場合はバディに代わって受領します。
4. 仲介者であることを理由に法令上の責任を排除しません。当社自身の故意・過失による損害には法令に従い責任を負います。
5. 内容、品質、許認可、現地運営、安全措置は提供バディが責任を負います。当社は掲載情報、通報、運営履歴に基づき必要な確認と措置を行うことがあります。

## 第6条 アカウント管理

1. 連絡可能なメールアドレスとプロフィールを最新に保ってください。
2. 認証情報の漏えいや不正利用を知った場合、直ちに当社へ通知してください。
3. 会員の責任による認証情報管理の不備で生じた損害は会員が負担します。ただし、当社の故意・過失がある場合を除きます。

## 第7条 情報・価格

1. バディは内容、日程、場所、所要時間、言語、含まれるもの・含まれないもの、参加条件、定員、価格、キャンセル条件を正確に掲載します。
2. 表示価格には通常の参加に必須と予想される費用を含めます。任意の現地費用や事前確定が難しい費用は、項目と概算範囲を詳細画面で明示します。
3. 詳細にない必須費用を現地で追加請求できません。
4. 明らかな誤記、システム障害、法令違反のおそれがある情報について、修正を求め、販売を停止できます。成立済みの予約に影響する場合、直ちにツーリストへ選択肢を案内します。

## 第8条 予約の成立

1. ツーリストが日時、人数、実決済額、キャンセル条件を確認し、キャンセル・返金ポリシーに必須同意のうえ決済を完了すると予約が確定します。
2. 決済待ちでは最大15分間、枠を仮確保することがあります。時間内に決済が完了しなければ申請は自動失効します。
3. 予約内容は完了画面、メールまたはサービス通知で提供します。
4. システム障害、重複予約、提供不能などの場合、当社またはバディは理由と返金方法を速やかに通知します。
5. 代表者は本人を含む全参加者が満19歳以上であることを確認します。安全・法令遵守のため、当社またはバディは合理的な範囲で年齢確認を求められます。

## 第9条 決済

1. 当社の提供する手段で、韓国ウォンまたは決済画面の通貨により支払います。
2. クーポンなどの割引後に実際に承認された金額を基準に決済・返金額を計算します。
3. 承認、返金処理期間、本人認証には決済事業者の規定も適用されることがあります。
4. 当社は完全なカード番号や決済パスワードを直接保存せず、決済事業者を通じて処理します。
5. バディのプラットフォーム手数料とその付加価値税は[バディ手数料・精算ポリシー](./buddy-commission-settlement-policy.ja.md)に従い、精算明細に区分表示します。

## 第10条 キャンセル・返金・日程変更

1. キャンセル、返金、バディのキャンセル・遅刻・無断欠席、重大な変更は[キャンセル・返金ポリシー](./cancellation-refund-policy.ja.md)に従います。
2. 会員は決済日から7日以内に法定の申込み撤回を請求できます。認められた場合、実決済額の全額を返金します。
3. 特定日時の予約サービスで、開始が迫っている、または提供が開始され、法令上の撤回制限事由が認められる場合、同ポリシーの48時間・24時間の一般キャンセル基準を適用します。
4. 申請・決済前に、法定撤回の可否、時点別返金額、実決済額基準、全文リンクを明示し、別途同意を得ます。
5. 日程、場所、内容の重大な変更にはツーリストの同意が必要です。同意しない場合、同ポリシーに従いキャンセルできます。

## 第11条 義務・禁止行為

会員は次の行為をしてはなりません。

1. 他人のアカウント・個人情報の無断利用や虚偽情報の提供
2. 決済・安全・紛争処理を回避するサービス外決済への誘導
3. 活動で得た連絡先の、履行・事後紛争処理以外の目的での利用
4. 差別、ヘイト、セクハラ、嫌がらせ、暴力、脅迫、ストーカー行為、違法行為、同意のない接触・撮影
5. 運営妨害やシステムへの不正アクセス
6. 著作権、肖像権、個人情報その他の権利の侵害
7. 報酬によるレビュー・評価操作や虚偽通報

詳細は[コミュニティ・安全ポリシー](./community-safety-policy.ja.md)に従います。

## 第12条 コンテンツ・レビュー

1. 投稿に必要な権利を有し、他人の個人情報・肖像は適法な同意の範囲でのみ掲載してください。
2. 会員は運営、表示、検索、翻訳、宣伝に必要な保存、複製、表示、形式変更の非独占的利用権を当社に付与します。削除・退会後、合理的なバックアップ・法定保存期間が終了すると利用権も終了します。
3. 違法、個人情報侵害、虚偽・操作レビュー、規約違反のコンテンツは一時遮断・削除でき、可能な場合は理由と異議申立て方法を案内します。
4. レビューは実際の予約・体験に基づいてください。否定的という理由だけでは削除しません。

## 第13条 利用制限・契約終了

1. いつでも所定の方法で退会を申請できます。未完了の予約、返金、精算、紛争がある場合、処理後に退会が完了することがあります。
2. 法令、本規約、個別ポリシー違反の程度に応じ、警告、投稿・予約制限、一時停止、契約終了が可能です。
3. 緊急の安全リスク、詐欺、反復する無断欠席、重大な違法行為を除き、事前に理由と是正機会を提供します。
4. 通知から14日以内に資料を添えて異議申立てができます。当社は合理的な期間内に再審査結果を通知します。

## 第14条 変更・中断

1. 保守、安全、設備・通信障害、不可抗力により一時中断でき、予測できる場合は事前に通知します。
2. 確定予約が履行不能となる場合、代替手段または返金手続きを案内します。
3. 無料の付加機能は変更できますが、成立済みの有料取引の権利を不当に制限しません。

## 第15条 損害賠償・責任

1. 当社または会員は、故意・過失で相手方に与えた損害について法令に従い責任を負います。
2. 天災、政府措置、交通規制など合理的に制御できない理由による不履行は、その範囲で責任が制限される場合があります。未提供分の返金は法令と返金ポリシーに従います。
3. 当社はバディの行為を保証しませんが、安全通報、決済保留、事実確認、必要な制限を合理的に実施します。
4. 当社の故意・重過失、生命・身体の損害、消費者保護法上排除できない責任は免除されません。

## 第16条 紛争処理

1. 予約内のサポート機能またはcontact@hanbuddy.krへ申し立てられます。
2. 双方の説明、メッセージ、写真、領収書、位置・決済記録を確認し、調整案を提示できます。
3. 会員は合理的な期間内に必要資料を提出し、当社は経過・結果を通知します。
4. 本規約は大韓民国法に基づき解釈し、訴訟は民事訴訟法上の管轄裁判所へ提起します。

## 第17条 通知

登録メール、サービス通知、告知により通知できます。全会員に共通する内容は7日以上の掲示で通知でき、重大な影響がある場合は個別通知も行います。
