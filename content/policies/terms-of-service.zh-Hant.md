# HanBuddy 服務條款

Version: 2026-09-07
Effective date: 2026-09-20

## 第1條 目的

本條款規定Zero One（以下簡稱“公司”）經營的HanBuddy網站及相關服務（以下簡稱“服務”）的使用條件、程序，以及公司與會員的權利、義務和責任。

## 第2條 定義

1. “會員”指同意本條款並創建帳戶的人。
2. “遊客”指搜索、預訂和支付夥伴所發佈活動的會員。
3. “夥伴”指通過公司審核批准，發佈並向遊客提供活動的會員。
4. “活動”指按夥伴設定的日程和內容提供的當地體驗、陪同、嚮導及附屬服務。
5. “預訂”指確認活動、日程、人數和金額並完成付款，從而訂立活動服務合同的行為。
6. “內容”包括會員發佈或發送的文字、照片、影片、評價、消息等全部資料。

## 第3條 公示與修改

1. 公司在易於查閱的位置公示本條款、商號、代表人、地址、聯繫方式、營業登記號碼及網絡銷售申報事項。
2. 公司可在合法範圍內修改條款。不利或重大修改須說明生效日與理由，提前30天通知；其他修改提前7天通知。
3. 對權利義務有重大影響的修改，依法需要時另行取得同意。
4. 未規定事項適用相關法律、具體政策及一般商業慣例。

## 第4條 資格與註冊

1. 僅限年滿19歲者註冊和使用。會員須在註冊及預訂時提供準確資訊。
2. 須使用本人Google帳戶等支持的認證方式，不得轉讓、出借或共享帳戶。
3. 以下情況可拒絕註冊或事後限制使用：
   - 使用他人資訊或虛假資訊
   - 未滿19歲
   - 曾因嚴重違反條款而受限
   - 以違法或違反公序良俗為目的
4. 夥伴發佈活動須另經審核批准；僅註冊不代表獲得活動提供權限。

## 第5條 合同當事人與公司角色

1. 公司與會員之間成立服務使用合同。
2. 活動合同原則上由發佈夥伴與預訂遊客訂立。活動詳情及付款頁面顯示提供者與主要交易條件。
3. 公司提供發佈、搜索、預訂、支付渠道連接、自動通知、客服和糾紛協調；收款時代表夥伴收取。
4. 公司不因中介身份排除法定責任，自身故意或過失造成的損害依法負責。
5. 內容、質量、許可、現場運營及安全由提供夥伴負責；公司可根據發佈資訊、舉報、運營記錄進行必要審查和處理。

## 第6條 帳戶管理

1. 會員須保持可聯繫的電子郵件及最新資料。
2. 發現認證資訊洩露或帳戶被盜用應立即通知公司。
3. 因會員責任未妥善管理認證資訊造成的損失由會員承擔，但公司存在故意或過失的除外。

## 第7條 活動資訊與價格

1. 夥伴須準確發佈內容、日程、地點、時長、語言、包含與不包含項目、參加條件、人數上限、價格及取消條件。
2. 顯示價格須包含正常參加所必需的預期費用。自選現場費用或難以預先確定的費用，須在詳情中說明項目與預計範圍。
3. 不得在現場另收詳情未披露的必要費用。
4. 對明顯錯誤、系統故障或涉嫌違法的資訊，公司可要求修改或停售。影響已有預訂時立即通知遊客並說明選項。

## 第8條 預訂成立

1. 遊客確認時間、人數、實際支付額及取消條件，必選同意取消與退款政策並完成付款後，預訂即確認。
2. 待付款時可臨時保留名額最多15分鐘；未及時付款，申請自動失效。
3. 確認頁面及郵件或服務通知提供預訂內容。
4. 因系統錯誤、重復預訂、無法提供等不能履約時，公司或夥伴及時說明原因和退款方式。
5. 預訂代表須確認包括本人在內的所有參加者年滿19歲。公司或夥伴可為安全和守法合理要求年齡核驗。

## 第9條 付款

1. 遊客使用支持的方式，以韓元或付款頁所示幣種付款。
2. 優惠券、促銷等折扣後的實際核准金額為付款記錄和退款的計算基礎。
3. 支付機構的規則也可能適用於授權、到賬時間及身份認證。
4. 公司不直接保存完整卡號或支付密碼，支付資訊通過支付機構處理。
5. 夥伴平台服務費及其增值稅依照[夥伴傭金與結算政策](./buddy-commission-settlement-policy.zh-Hant.md)，在結算明細中分別列示。

## 第10條 取消、退款與改期

1. 取消退款、夥伴取消、遲到、未到場、重大變更等遵循[取消與退款政策](./cancellation-refund-policy.zh-Hant.md)。
2. 會員可自付款日起7天內請求法定撤回。依法獲準時退還全部實際支付金額。
3. 對特定時間的預約服務，如活動臨近或已開始提供，且法定撤回限制理由成立，則適用48小時／24小時一般取消標準。
4. 公司在申請及付款前明確展示法定撤回可能性、各時點退款額、實付金額計算原則及全文鏈接，另行取得同意。
5. 日程、地點、內容的重大變更須獲遊客同意；不同意者可依政策取消。

## 第11條 義務與禁止行為

會員不得：

1. 盜用帳戶或個人資訊、提供虛假資訊。
2. 誘導站外支付以規避付款、安全及糾紛程序。
3. 將活動中獲得的聯繫方式用於活動履約、後續糾紛處理以外的目的。
4. 歧視、仇恨、性騷擾、欺凌、暴力、威脅、跟蹤、違法或未經同意接觸、拍攝。
5. 妨礙運營或未經授權訪問系統。
6. 侵犯版權、肖像、隱私及其他權利。
7. 有償操縱評價或虛假舉報。

具體遵循[社區與安全政策](./community-safety-policy.zh-Hant.md)。

## 第12條 內容與評價

1. 會員須擁有發佈所需權利，僅在合法同意範圍內發佈他人個人資訊或肖像。
2. 會員授予公司為運營、展示、搜索、翻譯和推廣所需的非獨佔存儲、複製、展示、格式轉換許可。刪除內容或註銷帳戶後，合理備份及法定保存期屆滿時許可終止。
3. 公司可暫時屏蔽或刪除違法、侵害隱私、虛假或操縱評價、違反政策的內容，並盡可能說明理由和申訴方式。
4. 評價須基於實際預訂和體驗；不會僅因負面評價而刪除。

## 第13條 限制與終止

1. 可隨時申請註銷；未完成預訂、退款、結算或糾紛可能須處理完畢後再完成註銷。
2. 公司可按違法或違反條款、政策的程度警告、限制內容或預訂、暫停或終止合同。
3. 除緊急安全風險、詐騙、重復未到場或嚴重違法外，事先告知理由並給予改正機會。
4. 可在限制通知後14天內附證據申訴；公司在合理期限內通知復核結果。

## 第14條 服務變更與中斷

1. 因維護、安全、設備或通信故障、不可抗力可暫時中斷；可預見時提前通知。
2. 無法履行已確認預訂時，說明替代方式或退款程序。
3. 可修改免費附加功能，但不得不當限制既有付費交易權利。

## 第15條 損害與責任

1. 公司或會員故意或過失導致對方損害時依法負責。
2. 天災、政府措施、交通管制等合理無法控制的原因可能在相應範圍限制責任；未提供活動的退款仍遵循法律及退款政策。
3. 公司不擔保夥伴行為，但合理受理安全舉報、暫緩支付、覈實事實並實施必要限制。
4. 本條款不免除公司故意或重大過失、生命身體損害及消費者保護法不可排除的責任。

## 第16條 糾紛處理

1. 可通過預訂客服或contact@hanbuddy.kr提交投訴和糾紛。
2. 公司可核查雙方陳述、消息、照片、收據、位置和付款記錄，提出協調方案。
3. 會員應在合理期限內提供覈實所需資料，公司告知進展和結果。
4. 本條款按大韓民國法律解釋；訴訟向民事訴訟法有管轄權的法院提起。

## 第17條 通知

公司可通過註冊電子郵件、服務通知或公告通知。普遍事項可公示至少7天，重大影響事項同時單獨通知。
