# 관리자 리뷰 관리

- 진입: 관리자 메뉴 → 리뷰 관리 (`/admin/reviews`).
- 선행 조건: backend #118의 관리자 리뷰 API와 Flyway V55가 적용된 서버, ACTIVE ADMIN 계정.
- 운영 데이터로 테스트하지 말고 검증용 활동과 실제 원본이 있는 후기를 사용한다.

## 제공 기능

목록은 작성자명, 활동 ID, 출처, 공개 상태를 기본 검색 조건으로 제공한다. 상세 검색에는 리뷰/회원/버디 ID, 원본 식별값, 별점, 원문 언어, 시스템 등록일 범위가 있다. 모든 조건은 AND이고 **내용 검색은 제공하지 않는다**. 등록일 범위는 한국 시간 기준이며 원본 작성일과 다르다.

기존 후기 등록은 한 번에 한 건만 가능하다. 정확한 활동 ID, 원본의 별점·내용과 등록 사유를 입력한다. 작성자명과 실제 작성일이 미상이면 비워 둔다. 등록 즉시 공개 및 평점 집계에 포함된다.

`sourceReference`는 직접 입력하지 않는다. 작성 화면의 첫 제출 시 UUID 기반 내부 요청 키를 생성하고, 같은 화면에서 실패 후 재시도할 때 유지한다. 서버가 이미 등록된 키라고 응답하면 해당 키로 등록 결과를 찾아 상세 화면으로 이동한다. 새 작성 화면(새로고침 포함)은 새 키를 사용하며 같은 내용의 별도 등록을 막지 않는다. 상세 정보와 고급 검색의 식별값은 운영 점검용으로만 남긴다.

이관 후기만 원문을 수정할 수 있다. 서비스에서 회원이 작성한 후기에는 수정 버튼이 없다. 숨김·복원은 두 출처 모두 가능하며 관리자 사유를 기록한다. 삭제 기능은 없다. 숨김 후기의 원문을 수정해도 공개되지 않는다.

번역 상태는 수동 새로고침으로 확인한다. 이전 버전 번역, 저장된 번역 없음, 원문 언어 미확인을 구분한다. 번역이 없다는 이유만으로 실패 또는 처리 중이라고 표시하지 않는다.

## 연동 확인 순서

1. Swagger에 `/admin/reviews`와 `/admin/activities/{activityId}/imported-reviews`가 존재하는지 확인한다.
2. 목록 필터 조합, 초기화, 페이지 이동을 확인한다. 검색 시 첫 페이지로 돌아가야 한다.
3. 검증용 이관 후기를 등록한다. 이름·날짜를 비운 경우 공개 활동 후기와 버디 프로필에서 익명으로 표시되고 임의의 작성일은 표시되지 않아야 한다.
4. 응답 유실을 가정한 재시도에서 같은 내부 키를 사용하는지, 중복 응답이면 기존 등록 상세로 이동하는지 확인한다. 새 작성 화면에서는 같은 내용도 새 키로 등록할 수 있어야 한다.
5. 이관 후기 원문 수정 후 번역 상태를 새로고침한다. 이름·별점만 변경한 경우와 본문 변경을 구분해서 확인한다.
6. 숨김 및 복원 후 공개 후기 목록, 평점·개수, 활동 카드와 버디 프로필을 다시 조회한다. 평점은 서버 응답을 사용한다.
7. 일반 회원의 후기에는 원문 수정이 없고 숨김·복원만 있는지 확인한다.
8. 권한 없음, 세션 만료, 잘못된 활동 ID, 서버 오류에서 성공으로 표시되지 않고 입력값이 유지되는지 확인한다.

브라우저 검증 폭은 390/768/1024/1440px이다. 관리자 UI는 기존 화면과 동일하게 한국어이며 공개 후기는 5개 서비스 언어의 익명 표시와 기존 번역/원문 전환을 사용한다. 변경한 브라우저의 관련 쿼리는 무효화하지만 다른 브라우저에 실시간 변경을 전송하지는 않는다.
