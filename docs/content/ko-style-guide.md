# 한국어 문구 기준

`src/messages/ko.json`을 쓰거나 고칠 때 따르는 기준이다. 영어 문장을 옮기지 말고, 같은 상황에서 한국 서비스가 실제로 쓸 말을 처음부터 쓴다.

## 듣는 사람

| 화면                                                    | 듣는 사람                                     | 비고                    |
| ------------------------------------------------------- | --------------------------------------------- | ----------------------- |
| 메인, FAQ, 예약·결제                                    | 한국어로 보는 게스트(한국에 사는 외국인 포함) | 다른 언어와 구성 동일   |
| 호스팅 소개(`/buddy`), 버디 가입, 활동 만들기, 대시보드 | 한국인 버디                                   | 모집 문구는 여기에 둔다 |
| About                                                   | 게스트와 버디·파트너 모두                     | 한쪽만 부르지 않는다    |

## 말투

- 메인·호스팅 소개·버디 가입·FAQ는 **해요체**로 통일한다.
- About의 이야기와 팀 소개는 **합니다체**로 통일한다. 한 페이지 안에서 섞지 않는다.
- 오류·로딩·법적 고지처럼 이미 합니다체로 쓰인 시스템 문구는 그대로 둔다.
- "~해 보세요"는 한 섹션에 한 번까지만 쓴다. 대부분은 "~해요", "~할 수 있어요"로 충분하다.

## 용어

| 쓰는 말       | 쓰지 않는 말                      | 설명                                                     |
| ------------- | --------------------------------- | -------------------------------------------------------- |
| 활동          | 액티비티, 체험                    | 버디가 여는 상품 전체                                    |
| 코스 항목     | 활동(세부)                        | 활동 만들기의 일정표(itinerary) 한 칸                    |
| 게스트        | 여행자, 참여자                    | 활동에 참여하는 사람. 채팅방 구성원을 뜻할 때만 "참여자" |
| 신청자        | 지원자                            | 활동을 신청한 게스트                                     |
| 버디          | 호스트, 로컬 가이드               | 활동을 여는 한국인. 관광통역안내사도 "가이드 버디"       |
| 한국인 버디   | 현지 버디, 로컬 버디, 한국 현지인 | 설명이 필요할 때                                         |
| 파트너        | 업체 호스트                       | 파트너 활동을 여는 지역 업체                             |
| 한버디        | HanBuddy                          | 본문의 서비스 이름                                       |
| HanBuddy      | 한버디                            | 로고, 메타 제목의 `\| HanBuddy`, 약관·동의 항목 이름     |
| 버디 신청하기 | 버디로 시작하기, 버디 여정        | 버디 가입 버튼                                           |

## 피할 표현

- **당신**: 주어를 빼거나 "내가", "나만의"로 바꾼다.
- **제목 끝 마침표**: 제목, eyebrow, 버튼에는 마침표를 찍지 않는다. 문장형 설명에는 찍는다.
- **영어 명사 직역**: "커뮤니티의 이야기", "버디 워크스페이스", "계속 소통해요" 대신 "게스트 후기", "버디 대시보드", "문의하기".
- **영어 구조 직역**: "~가 되어야 하는 이유"(Why become), "~을 명확하게 운영하세요", "~의 실제 순간".
- **근거 없는 약속**: 응답 시간, 수익 금액, 재고·마감 임박 문구는 정책이나 데이터가 있을 때만 쓴다.

## 바꾸지 않는 것

- 회차 수, 게스트 수, 평점, 환불 비율, 마감 시간, 결제 수단 같은 사실.
- 메시지 키와 ICU 문법(`{count, plural, ...}`, `<nowrap>`, `<emphasis>`).
