# 정책 열람 후 원래 화면으로 복귀

실행한 브라우저 시나리오와 아직 완료하지 않은 전체 QA 범위는 [PR #101 검증 기록](qa/2026-09-07-pr-101-review.md)에 구분해 기록한다. 아래 회귀 시나리오 목록 자체를 검증 완료 증빙으로 취급하지 않는다.

정책 페이지의 뒤로가기 버튼은 홈 링크가 아니라 브라우저의 이전 항목으로 이동한다.
이전 항목이 없는 직접 방문에만 현재 언어의 홈을 대체 경로로 사용한다.

## 입력값 보존 방식

- `[locale]/@policy/(.)policies/[slug]`가 사이트 안에서의 정책 링크 이동을 처리한다.
- 정책 URL은 변경되지만 원래 페이지는 병렬 라우트에 마운트된 상태로 유지된다.
- 정책 본문은 전체 화면 다이얼로그로 표시하며, 배경은 상호작용과 스크롤을 막는다.
- 날짜, 인원, 요청사항, 체크 상태, 프로필 입력값과 선택한 파일을 별도 직렬화하거나
  localStorage에 저장하지 않는다. 원래 컴포넌트의 상태 자체를 유지한다.
- 화면 뒤로가기, 브라우저 뒤로가기, Escape는 같은 브라우저 히스토리를 사용한다.
  다른 정책으로 이동했다면 직전에 읽던 정책부터 순서대로 돌아온다.
- 푸터, 로그인 안내, 정책 본문의 내부 링크는 기존 Next Link를 유지한다.
- 기본 슬롯과 홈/다른 경로의 빈 슬롯은 직접 방문 시 중복 화면이나 남은 정책을 방지한다.

정책 URL 직접 접속·새 탭·새로고침은 기존 독립 정책 페이지를 렌더링한다.
이 기능은 같은 탭에서 정책을 읽고 돌아오는 동안의 상태 보존이며, 새로고침이나
탭 종료 이후까지의 영구 초안 저장은 아니다. 가입/활동 작성의 기존 초안 저장 기능은 유지한다.

## 확인할 회귀 시나리오

1. 입력 화면 → 푸터 정책 → 화면 뒤로가기: 원래 URL과 입력값이 유지되는지.
2. 입력 화면 → 정책 → 다른 정책 → 브라우저 뒤로가기 두 번: 원래 폼 복귀.
3. 브라우저 앞으로가기로 정책이 다시 열리는지.
4. 기존 가입/환불 팝업 → 본문 정책 링크 → 뒤로가기: 입력값이 유지되는지.
5. 정책 URL 직접 방문과 새로고침에서도 본문·번역·뒤로가기가 동작하는지.
6. 영어/한국어 390, 768, 1024, 1440px에서 본문 스크롤과 포커스를 확인한다.
